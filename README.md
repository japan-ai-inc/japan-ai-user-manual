# JAPAN AI Studio ユーザーマニュアル

> 本マニュアルは、JAPAN AI Studio（以下「Studio」）の機能と操作方法を、運用担当者・利用者の視点から整理したものです。
>
> - 対象読者: Studio を導入・運用する管理者、ワークフロー作成者、利用者
> - 想定バージョン: 2026 年 5 月時点の本番リリース版
> - 表記: UI 上のラベルは「」で囲み、画面上の表記をそのまま記載しています
> - 数値（サイズ・件数・タイムアウト等）は記載時点の代表値で、契約プランや組織設定により変動する場合があります
>
> **API 経由でプログラム連携を行う場合は、本マニュアルと併せて以下の API ガイドを参照してください：**
>
> - エージェント・チャット API ガイド（`/api/agent-chat`）
> - STUDIO カスタムオブジェクト API ガイド
> - STUDIO ストレージ API ガイド
> - ワークフロー・トリガー・ノード・タスクスケジューラ機能説明書
