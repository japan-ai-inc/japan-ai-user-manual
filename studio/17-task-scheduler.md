# 17. タスクスケジューラとメモリ管理

### 17.1 タスクスケジューラ

タスクスケジューラは、**エージェント** または **ワークフロー** を定期実行する機能です。設定画面 →「エージェント」→「タスクスケジューラ」から、対象タスクの作成・一覧確認・更新・削除を行えます。

> **重要**：ワークフローの「開始（Start）」ノードのトリガーとは別機能です。Start ノードのトリガーは外部イベント駆動（Webhook、メール、ストレージ変更など）に用い、定期実行はタスクスケジューラを使います。

- 対象タイプ：エージェント / ワークフロー
- タイムゾーン：**Asia/Tokyo（JST）固定**
- 通知：JAI 通知センター・メール

#### 繰り返しパターン

| パターン | 説明 |
|---|---|
| NONE | 1 回限り |
| HOURLY | 毎時、同じ分に実行 |
| DAILY | 毎日、同じ時刻に実行 |
| WEEKDAYS | 月〜金、同じ時刻に実行 |
| WEEKLY | 毎週、同じ曜日・時刻に実行 |
| MONTHLY | 毎月、同じ日・時刻に実行 |
| CUSTOM | ユーザー指定の間隔（下表） |

#### カスタム間隔の選択肢

| 単位 | 指定可能な間隔 |
|---|---|
| 分 | 10、15、20、30 |
| 時 | 1、2、3、4、6、8、12、24 |

> 任意のクーロン式や 1 分単位の頻度は現バージョンでは指定できません。

> **画面プレースホルダー**：`screenshots/17-task-scheduler.png`

### 17.2 メモリ管理

エージェントの記憶（会話履歴・ユーザー固有メモリ）を管理します。記憶は次の階層で構成されます。

| 階層 | 内容 | 自動読込 |
|---|---|---|
| プロファイル | ユーザー個別の基本情報 | 常時 |
| 日次コンテキスト | 直近の日次サマリ | 常時 |
| 保存済みメモリ | 任意の知識・事実（ユーザー／組織／プロジェクト／エージェント単位でスコープ） | 必要時 |
| 会話履歴 | 過去のチャット履歴（チャット履歴データベース＋ベクトル検索） | 必要時 |

メモリ管理画面では、参照・削除・スコープ変更・利用上限の確認が可能です。

メモリスコープ:

- `@user`：個人の記憶（本人のみ）
- `@org`：組織共通
- `@project`：プロジェクト共通
- `@agent`：エージェント単位

### 17.3 標準値

| 項目 | 値 |
|---|---|
| エージェントのチャット文脈件数 | 既定 100（上限 1,000） |
| エージェントの最大ファンクションコール深さ | 既定 20（上限 200） |
| プロンプトキャッシュ | Anthropic / Google 系モデルで標準有効 |

ワークフロー側のノード固有のパラメーター（サブワークフローの再帰深さ、イテレーション並列数、エージェントノードの最大反復回数など）は [19 章](19-node-reference.md) を参照してください。
