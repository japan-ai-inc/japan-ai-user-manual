# 19. ノードリファレンス

各ノードの設定項目は右パネルに表示されます。代表的な項目を示します。

### 19.1 開始（Start）

- トリガータイプ（[20 章](20-trigger-reference.md) 参照）
- 入力変数（フィールド名と型）
- トリガー出力（Webhook 等）

### 19.2 終了（End）

- 出力変数（外部に返す変数の選択）
- ワークフロー全体の最終出力を確定

### 19.3 LLM

| パラメーター | 説明 |
|---|---|
| モデル | プロバイダーとモデル名（チャット / コンプリーションモード） |
| 完了パラメーター | 温度（temperature）、最大トークン、top_p、frequency_penalty 等 |
| プロンプトテンプレート | チャット形式（system / user / assistant）または Jinja2 形式 |
| プロンプト変数 | テンプレートで参照する変数の宣言 |
| メモリ | 会話履歴の利用有無 |
| コンテキスト | 追加コンテキスト変数の注入 |
| ビジョン | 画像入力の有効化（モデル対応時） |

### 19.4 コード（Code）

| パラメーター | 説明 |
|---|---|
| 言語 | Python3 または JavaScript |
| ソースコード | サンドボックス内で実行されるコード |
| 入力変数 | コードに渡される変数群 |
| 出力スキーマ | 出力変数の名前と型 |
| サンドボックス共有 | 繰り返し処理で同一サンドボックスを再利用するか |

サンドボックスの主な制限：実行時間 60 秒、文字列最大 8 万文字、配列最大 1 万要素、ネスト 5 段。

### 19.5 IF ELSE

| パラメーター | 説明 |
|---|---|
| 条件式 | 変数とリテラルを比較する論理式（`==`, `!=`, `<`, `>`, `<=`, `>=`, `&&`, `||`, `!`） |
| 分岐 | 複数条件を上から評価、最初の真分岐を実行 |

### 19.6 繰り返し（Iteration）

| パラメーター | 説明 |
|---|---|
| 入力配列 | 繰り返し対象 |
| 並列実行 | true / false |
| 並列数 | 上限 10（標準） |
| エラー処理 | `TERMINATED` / `CONTINUE_ON_ERROR` / `REMOVE_ABNORMAL_OUTPUT` |
| 出力 | 各反復の結果配列 |

### 19.7 ツール（Tool）

| パラメーター | 説明 |
|---|---|
| ツール選択 | プロジェクトで利用可能なスキルから選択 |
| 入力マッピング | スキルのパラメーターに上流ノードの変数を割当 |
| 出力 | スキルの戻り値 |

### 19.8 エージェント（Agent）

| パラメーター | 説明 |
|---|---|
| エージェント | 呼び出すエージェントの選択（ID またはラベル） |
| クエリ | エージェントに渡すメッセージ・タスク文 |
| モデル上書き | 使用モデルを明示指定（任意） |
| 温度 / 最大トークン数 | LLM 生成パラメーターの上書き（任意） |
| 最大反復回数 | エージェントノード内のループ上限（任意指定） |
| サンドボックス共有 | コードノード等とサンドボックスを共有するか（既定 true） |
| タイムアウト | 実行タイムアウト（既定 120 秒） |
| エージェントツール | 有効化するツール一覧（任意） |
| 入力ファイル | 上流ノードのファイル変数を渡す |

### 19.9 サブワークフロー（Sub-Workflow）

| パラメーター | 説明 |
|---|---|
| ワークフロー | 呼び出すワークフロー |
| バージョン | 実行するバージョン（`latest` / `draft` / 特定スナップショット） |
| 入力マッピング | サブの開始ノード変数への割当 |
| 出力マッピング | サブの終了ノードからの戻り値を親で利用するための割当 |
| 最大ネスト深さ | 再帰防止（既定 5、設定範囲 1〜10） |
| タイムアウト | 実行タイムアウト（既定 300 秒） |

### 19.10 データ連携（Knowledge Retrieval）

| パラメーター | 説明 |
|---|---|
| データセット | 検索対象 |
| クエリ | 入力変数による検索文字列 |
| top_k | 取得件数 |
| フィルター | フィールド条件 |

### 19.11 質問分類（Question Classifier）

| パラメーター | 説明 |
|---|---|
| 入力 | 分類対象テキスト |
| モデル | 分類に使う LLM |
| クラス一覧 | 名前と説明のリスト |
| 指示文（任意） | 分類用カスタムプロンプト |

### 19.12 テンプレート（Template Transform）

- テンプレート文字列（Jinja2 構文）
- 利用する変数の宣言
- 出力：レンダリングされた文字列

### 19.13 テキスト抽出（Document Extractor）

- 入力ファイル変数
- 抽出スキーマ（JSON で定義）
- 出力：構造化オブジェクト

### 19.14 JSON Parse

- 入力テキスト
- 期待スキーマ
- 出力：パース済みオブジェクトまたはエラー

### 19.15 カスタムオブジェクト SQL

- SQL クエリ（[11.7](11-custom-objects.md) 参照）
- バインド変数（上流ノードから）
- 出力：SQL 結果（rows / count）
