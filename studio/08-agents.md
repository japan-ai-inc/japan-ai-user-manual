# 8. エージェント

### 8.1 エージェントとは

エージェントは、**システムプロンプトと一連のスキルを備えた AI** で、チャット画面・ワークフロー内のエージェントノード・ページ等から呼び出されます。

### 8.2 エージェントの設定項目

設定画面 →「エージェント設定」から、エージェントを作成・編集できます。主な設定:

| 項目 | 説明 |
|---|---|
| 名前 / 説明 / アイコン | 識別用情報 |
| エージェントタイプ | チャット / 検索 / バッチ / マルチエージェント等 |
| デフォルトモデル | 使用する LLM |
| モデルモード | 「自由（free）」: ユーザーが任意のモデルを選択可／「固定（fixed）」: 指定モデルのみ |
| 利用可能モデル | ホワイトリスト指定（任意） |
| システムプロンプト | エージェントの役割・指示 |
| スキル（ツール） | 利用可能なツールのリスト（[9 章](09-skills.md)） |
| データセット | デフォルトで参照するデータセット（RAG） |
| メモリ | 長期記憶の有効・無効 |
| チャット文脈の長さ | 直近の会話を何件まで保持するか（既定 100、上限 1,000） |
| 最大ファンクションコール深さ | エージェントが連続して呼べるツール呼び出しの上限（既定 20、上限 200） |
| ビジョン | 画像入力の有効・無効（モデル依存） |
| 添付可能ファイル形式 | PDF・画像・CSV・Excel・Word・PowerPoint 等 |
| プロンプトキャッシュ | Anthropic / Google モデルでのキャッシュ動作 |

> **画面プレースホルダー**：`screenshots/08-agent-settings.png`

### 8.3 対応モデル

利用可能なモデルは、組織の契約・地域・プランによって異なります。代表的に Anthropic Claude 系（4.x Opus / Sonnet 等）、OpenAI GPT 系、Google Gemini 系などが選択可能です。

- 画像入力対応モデル：選択時に「ビジョン」フラグが表示されます
- 拡張思考（Reasoning）対応モデル：Claude 4.6+ 等で「推論」設定が可能
- プロジェクト・組織側でモデルを制限している場合、一覧に表示されません

### 8.4 エージェントの利用シーン

- **チャット画面** からの対話
- **ワークフローのエージェントノード** から呼び出し
- **ページ** にエージェントを埋め込んで業務 UI 化
- **API キー経由** での外部システムからの呼び出し（[18 章](18-api-keys-audit-log.md)）

### 8.5 マルチエージェント / サブエージェント

エージェントは設定により他のエージェントへのタスク委譲（`delegate_work`）が可能です。専門領域に特化したサブエージェントを束ねるオーケストレーター構成にも対応します。
