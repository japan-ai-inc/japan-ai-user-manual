# 1. Studio とは

Studio は、JAPAN AI プラットフォーム上で **AI アプリケーション（プロジェクト）を構築・運用するための統合開発環境** です。コーディングを行わずに、画面上でノードを組み合わせる形式でワークフローやエージェントを構築できます。

Studio で扱える代表的なユースケース:

- **対話エージェント**（プロンプト・ナレッジ・ツールの組み合わせ）
- **ワークフロー** による業務処理の自動化（手動／スケジュール／Webhook／メール／ストレージ／カスタムオブジェクト等のイベント起動）
- **検索拡張型応答（RAG）**：社内文書・外部 SaaS と接続したナレッジ検索
- **カスタムオブジェクト**：業務データのスキーマ定義・レコード管理・SQL アクセス
- **ページ**：プロジェクト内向け Web 画面・フォームの内製
- プロジェクト単位の **権限管理・監査ログ**
