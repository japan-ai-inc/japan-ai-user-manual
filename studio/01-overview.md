# 1. Studio とは

Studio は、JAPAN AI プラットフォーム上で **AI アプリケーション（プロジェクト）を構築・運用するための統合開発環境** です。コーディングを行わずに、AIビルダーや画面上でノードを組み合わせる形式でワークフローやエージェント、ページを構築できます。

Studio で扱える代表的なユースケース:

* **対話エージェント**（永続な記憶を持たせたAIエージェントの開発）
* **ワークフロー** による業務処理の自動化（手動／スケジュール／Webhook／メール／ストレージ／カスタムオブジェクト等のイベント起動）
* **CRM・ダッシュボード**：カスタムオブジェクトで業務データのスキーマ定義・レコード管理・SQL アクセスとエンドユーザー向けページの構築
* AIネイティブアプリケーション：AIエージェントとページを組み合わせることでAIネイティブなアプリケーションが構築可能
* プロジェクト単位の **権限管理・監査ログ**
