# 4. 画面構成と基本ナビゲーション

### 4.1 グローバルナビゲーション

JAPAN AI にログインすると左サイドバーが表示され、その中に **「STUDIO」** という項目があります。クリックすると Studio のトップページ（プロジェクト一覧）に遷移します。

- URL の例: `/{organization_id}/studio`

> **画面プレースホルダー**：`screenshots/04-global-nav.png`

### 4.2 プロジェクト一覧

Studio トップ画面では以下の要素が表示されます。

- ヘッダー：「STUDIO」アイコン＋以下の説明文
  > 「プロジェクト単位でデータ、ワークフロー、外部連携を統合管理し、AI がプロジェクト全体の文脈を理解して最適な支援を提供します。」
- 検索欄：「プロジェクト名で検索」
- ボタン：「+ プロジェクト作成」
- プロジェクト一覧テーブル（列）：
  1. プロジェクト名
  2. 説明
  3. メンバー
  4. 作成日時
  5. 操作
- タブ（IAM 強化モードが有効な場合）：
  - 「参加中のプロジェクト」
  - 「すべてのプロジェクト」

### 4.3 プロジェクト内ナビゲーション

プロジェクトを開くと、左サイドバーがプロジェクト用のメニューに切り替わります。

1. **お気に入りタスク**（折りたたみ式）
2. **最近のタスク**（最大 30 件、「すべて見る」で全件表示）
3. **リソースナビゲーション**（アイコン横の英字ラベルが画面に表示）
   - エージェント（AGENT）
   - カスタムオブジェクト（OBJECT、機能有効時のみ）
   - ページ（PAGE、機能有効時のみ）
   - ストレージ（STORAGE）
   - データ連携（DATASET）
   - ワークフロー（WORKFLOW）
4. **設定（歯車アイコン）**：プロジェクトの各種設定画面へ遷移

> **画面プレースホルダー**：`screenshots/04-project-sidebar.png`

### 4.4 設定画面の構成

歯車アイコン → 設定画面では、サイドバーに次のセクションが表示されます。

| カテゴリ | 項目 |
|---|---|
| 基本設定 | 基本設定 / メンバー |
| アクセス制御 | ロール設定 / シークレット管理 |
| 外部接続 | データ連携 / データ連携 API / ツール設定 |
| エージェント | エージェント設定 / タスクスケジューラ / メモリ管理 / スキル |
| デベロッパー | MCP サーバー設定 / API キー管理 / 監査ログ |

### 4.5 プロジェクト ダッシュボード

プロジェクトトップでは、設定済みの **ホームページ** が表示されます（ページ機能が有効な場合）。未設定の場合は、次の要素を含む既定のダッシュボードが表示されます。

- 最近編集したページの一覧
- エージェント一覧
- プロジェクトアシスタント用のチャットウィジェット
