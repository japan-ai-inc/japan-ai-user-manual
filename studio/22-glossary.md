# 22. 用語集

| 用語 | 説明 |
|---|---|
| 組織 (Organization) | JAPAN AI を利用するテナント単位 |
| プロジェクト | Studio 内の作業単位 |
| ワークフロー | ノードを組み合わせた自動化フロー |
| ノード | ワークフロー上の一処理単位 |
| トリガー | ワークフローを起動するイベント |
| エージェント | プロンプトとスキルを備えた AI |
| スキル（ツール） | エージェント・ワークフローが呼び出せる機能 |
| データセット（ナレッジ） | 検索用に取り込まれた文書・データの集合 |
| カスタムオブジェクト | 業務データのテーブル定義とそのレコード |
| ページ | ノーコードで作成する Web ページ／フォーム |
| シークレット | 暗号化保管される機密情報 |
| 外部接続（コネクタ） | 外部 SaaS との認証情報 |
| MCP | Model Context Protocol。AI ツールを共通プロトコルで連携 |
| メモリ | エージェントが保持する記憶（プロファイル・日次・保存済み・会話履歴） |
| 公開（パブリッシュ） | ワークフローを利用可能な状態に切り替えること |
| 下書き | 編集中で未公開の状態 |
| ロール | プロジェクト／組織におけるユーザー権限 |
| JRN | Japan Resource Name。Studio リソースの統一識別子 |
| リソースポリシー | 個別リソースに付与する許可・拒否ステートメント |
| 監査ログ | 操作履歴の記録 |
