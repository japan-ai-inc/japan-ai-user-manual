# 13. ページ

### 13.1 概要

「ページ」は、プロジェクト内で利用できる **静的 Web アプリホスティング機能** です。サイドバーには「ページ（PAGE）」として表示されます（機能有効時のみ）。

ページは **事前にビルドした Web アプリ（HTML/JS/CSS 等を ZIP にまとめたもの）をアップロードして配信する** 仕組みで、プラットフォーム側がアクセス制御・バージョン管理・サービスアカウント実行・iframe ホスティングを提供します。**画面上で要素をドラッグして組み立てるノーコードビルダーではありません。**

ホストされたページからは、プラットフォームのプロキシ API（`/api/agent-chat`、`/api/storage`、`/api/custom-objects` など）を、追加認証なしで呼び出せます。フロントエンドのフレームワークは任意（Next.js / React / 静的 HTML 等）です。

### 13.2 主な操作（画面）

- 新規ページの作成（名前・サムネイル・アイコン）
- 「ZIP をアップロード」ボタンから ZIP ファイルをアップロード
- 「新しいバージョンをアップロード」で更新
- 「バージョン履歴」から任意バージョンをアクティブに切り替え
- 「アクセス設定」で認証モードを変更
- ページの編集（名前・サムネイル）・削除

> **画面プレースホルダー**：`screenshots/13-pages.png`

### 13.3 ZIP パッケージの要件（既定）

- 1 ZIP ファイルの最大サイズ：**100 MB**
- 展開後の合計サイズ：**200 MB 以内**
- 既存ページに同名でアップロードすると上書き（明示確認あり）
- 不正な ZIP・ZIP 爆弾の可能性があるファイルはアップロード不可

### 13.4 認証モード

| モード | 動作 |
|---|---|
| 必須（REQUIRED） | JAPAN AI ログイン必須。ログインユーザーとして動作 |
| 任意（OPTIONAL） | ログイン済みならユーザー、未ログインはサービスアカウントとして動作 |
| 匿名（ANONYMOUS） | 常にサービスアカウントとして動作（公開リンク向け） |

匿名モードでは、外部公開用の短命トークン付き URL が発行されます。

### 13.5 プラットフォーム API の呼び出し

ホストされたページから次の API を呼び出せます（詳細は付属の API ガイドを参照）。

- `/api/agent-chat`：LLM・エージェント呼び出し（ストリーミング / 非ストリーミング、長時間処理の Handoff 対応）
- `/api/storage/...`：プロジェクトストレージへのファイル操作
- `/api/custom-objects/v1/...`：カスタムオブジェクトへの REST / SQL アクセス

セッションクッキーは自動的に送信されるため、ページ側のコードから明示的に認証ヘッダーを設定する必要はありません。

### 13.6 バージョン管理

ページは **バージョン管理** されます。

- アップロードごとに新バージョンが作成
- 任意のバージョンをアクティブに切り替え可能（切り戻し対応）
- 旧バージョンは保持

### 13.7 権限

| 権限 | 内容 |
|---|---|
| `studio.page.read` | ページの参照 |
| `studio.page.create` | 新規ページの作成 |
| `studio.page.update` | 編集・新バージョン公開 |
| `studio.page.delete` | ページの削除 |

### 13.8 ユースケース

- 業務フォーム（社内申請、データ入力など）を Next.js 等で作成して配布
- カスタムオブジェクトのレコード閲覧・編集 UI を内製
- エージェントを埋め込んだチャット UI
- ワークフロー実行ボタン付きの社内ダッシュボード
