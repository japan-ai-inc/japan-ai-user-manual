# 6. プロジェクト管理

### 6.1 プロジェクトの作成

1. Studio トップで「+ プロジェクト作成」をクリック
2. 入力ダイアログで以下を設定
   - プロジェクト名（必須）
   - 説明
   - アイコン
3. 「作成」ボタンを押すと、プロジェクト詳細画面に遷移します

プロジェクト数の上限は契約プランによって異なります。上限に達している場合は作成時にエラーメッセージが表示されます。

> **画面プレースホルダー**：`screenshots/06-create-project.png`

### 6.2 プロジェクトの編集・削除

一覧の「操作」列から実行できます。

- 編集：名前・説明・アイコンの変更
- 削除：プロジェクト全体の削除（関連リソースを含む）

### 6.3 プロジェクト基本設定

設定画面 →「基本設定」で次の項目を編集できます。

- プロジェクト名、説明、アイコン
- 公開状態（下書き／公開／アーカイブ）
- ホームページ（ページ機能が有効な場合、特定のページをプロジェクトのトップに設定可能）
- 機能の有効・無効（カスタムオブジェクト、ページ など、組織側の機能フラグに応じて表示）
