# 18. API キー・監査ログ

### 18.1 API キー管理

設定画面 →「デベロッパー」→「API キー管理」で、外部システムから JAPAN AI を呼び出すための API キーを発行・失効できます。

- キー名、発行日、最終利用日時の確認
- スコープ設定（読み取り／書き込み／実行など）
- 組織レベル / プロジェクトレベルの 2 種類

組織レベルの API キーは「組織 API キー」ロール（`jai:global:api_key`）に紐付き、モデル呼び出し・エージェント呼び出し・ワークフロー実行・データセット参照などのアクションに制限されます。

### 18.2 監査ログ

組織管理者向けに、Studio 内の主要操作の履歴を時系列で参照できます。

- 操作日時、対象リソース（JRN）、実行ユーザー
- アクション種別（作成・更新・削除・参照等）
- フィルター（日付、ユーザー、操作種別）

監査ログ閲覧には `iam.audit.read` 権限が必要です。
