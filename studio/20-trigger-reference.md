# 20. トリガーリファレンス

ワークフローの「開始（Start）」ノードで設定するトリガーの一覧です（既定は手動トリガー）。1 つのワークフローに複数の開始ノードを置き、異なるトリガーを併用できます（マルチトリガー）。

> 定期実行（毎日 9 時など）はトリガーではなく **タスクスケジューラ** で設定します。[17.1](17-task-scheduler.md) を参照してください。

各トリガーの表示・利用可否は、組織側の機能トグル設定に依存します。

### 20.1 手動トリガー

- 入力フィールドのみ定義
- 「手動実行」ボタンや、ページのボタンコンポーネントから起動

### 20.2 Webhook トリガー

| 設定項目 | 説明 |
|---|---|
| Webhook URL | 公開時に発行（外部システムに設定） |
| 署名検証プロバイダー | 「GitHub 形式」「Slack 形式」「カスタム（HMAC-SHA256）」から選択 |
| 署名ヘッダー | 検証に使うヘッダー名 |
| Webhook シークレット | プロバイダーと共有する秘密鍵 |
| クエリパラメータ | リクエストの query から変数を抽出 |
| ヘッダーパラメータ | ヘッダーから変数を抽出 |
| ボディパラメータ | リクエスト本文から JSONPath 等で変数を抽出 |
| カスタムレスポンス | 任意のステータスコードと本文を返却可能 |

- 認証はタイミング攻撃耐性のある比較（`timingSafeEqual` 等）で検証
- Slack 形式では「5 分以内のタイムスタンプ」を要求
- レート制限は Webhook ID 単位で適用

> **画面プレースホルダー**：`screenshots/20-webhook-trigger.png`

### 20.3 データセットトリガー

- 対象データセット ID
- イベント種別：
  - `itemCreated`（アイテム追加時、インデックス完了後）
  - `itemUpdated`（アイテム更新時）
  - `itemDeleted`（アイテム削除時）

### 20.4 カスタムオブジェクトトリガー

- 対象オブジェクト
- イベント：`recordCreated` / `recordUpdated` / `recordDeleted`
- 監視フィールドの指定（特定フィールド変更時のみ起動）
- 条件フィルター（フィールド値での絞り込み）

### 20.5 ストレージトリガー

- 対象フォルダ（フォルダ単位の指定）
- イベント：
  - `folderCreated`（フォルダ：新規作成）
  - `fileCreated`（ファイル：新規アップロード）
  - `fileUpdated`（ファイル：更新）
  - `fileDeleted`（ファイル：削除）
- フィルター条件：ファイル名・拡張子・ファイルサイズなど

### 20.6 Gmail / Outlook トリガー

- 接続中のメールアカウントから新着メールを起点に起動
- ラベル / フォルダフィルター、件名・本文条件などでフィルタリング
- 認証は OAuth 経由（[16 章](16-connectors-mcp.md)）
- イベントペイロード：差出人、件名、本文、添付ファイル

### 20.7 Email by JAI トリガー

- JAI プラットフォーム提供のメール機能で受信したメールを起点に起動
- イベントペイロード：差出人、件名、本文、添付ファイル
