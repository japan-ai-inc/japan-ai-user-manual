# 10. データ連携（ナレッジ）

### 10.1 概要

「データ連携」は、社内文書や外部データソースを取り込み、AI が検索（RAG）に利用できる形にする機能です。サイドバーには「データ連携（DATASET）」として表示されます。

データセットは「複数のドキュメントを束ねたインデックス」で、内部で **テキスト抽出 → チャンク分割 → 埋め込み → ベクトル + 全文インデックス保存** の処理が行われます。

### 10.2 対応ファイル形式

| 区分 | 形式 |
|---|---|
| 文書 | PDF、Word（DOCX/DOC）、Excel（XLSX/XLS）、PowerPoint（PPTX/PPT）、HTML、テキスト、Markdown、CSV、MBOX（メール） |
| 画像 | JPEG、PNG、WebP、HEIF、HEIC（OCR・画像理解の対象） |
| 構造化データ | JAI 提供の音声書き起こしフォーマット、Slack / Chatwork のエクスポート JSON |

- **1 ファイルあたりの最大サイズ**：200 MB
- URL リスト（テキストファイル）の取り込みにも対応

### 10.3 外部データソースとの連携

以下のデータソースとの自動同期に対応しています。

- Google Drive
- OneDrive / Microsoft 365
- Slack（チャンネル履歴）
- Chatwork
- メール（MBOX）

各コネクタの認証情報は組織・ユーザー単位で安全に保管されます（[16 章](16-connectors-mcp.md)）。

> ご利用環境により対応コネクタは変動します。具体的なラインナップは導入元にご確認ください。

### 10.4 取り込みパイプライン（ユーザーから見える流れ）

1. ファイルをアップロードする、または外部ソースから同期する
2. 取り込みジョブが作成され、ステータスが「処理中（PROCESSING）」になる
3. テキスト抽出（必要に応じて OCR）→ チャンク化 → 埋め込み生成 → インデックス保存
4. 完了すると「完了（COMPLETED）」、エラー時は「失敗（FAILED）」と表示
5. 失敗したアイテムは原因表示付きで再試行可能

### 10.5 検索（RAG）

データ連携ノードや、エージェントの `rag_search` スキルから検索を実行します。代表的なパラメーター:

| パラメーター | 説明 |
|---|---|
| クエリ | 検索文字列（ユーザーの質問など） |
| top_k | 取得する上位件数（既定値の目安は 5〜10） |
| フィルター | データセット ID、フィールド条件 |
| 引用情報 | ファイル名・ページ番号・URL 等の出典情報が結果に付与されます |

検索は **ベクトル類似度 + 全文検索** のハイブリッド方式で動作し、関連スコア順に結果を返します。

### 10.6 権限

データセットに対する代表的な権限:

| 権限 | 内容 |
|---|---|
| `jai.dataset.read` | データセットの参照 |
| `jai.dataset.create` | 新規データセットの作成 |
| `jai.dataset.update` | データセット設定の変更 |
| `jai.dataset.delete` | データセットの削除 |
| `jai.dataset.document.{read,create,update,delete}` | ドキュメント単位の操作 |

詳細なロール対応は [21 章](21-roles-permissions.md) を参照してください。

### 10.7 制限値（標準）

| 項目 | 標準値 |
|---|---|
| 1 ファイル最大サイズ | 200 MB |
| データセット数 / 容量 | 契約プラン依存 |
| 自動同期の頻度 | 時間単位／日次／週次から選択 |
