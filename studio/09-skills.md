# 9. スキル（ツール）

### 9.1 スキルとは

スキルは、エージェントやワークフローが利用できる **再利用可能な機能単位** です。プラットフォーム標準のスキルに加え、組織・プロジェクト固有のスキルを登録できます。

### 9.2 スキルの分類

| 分類 | 概要 |
|---|---|
| ビルトインスキル | プラットフォームが提供する標準機能（Web 検索、画像生成、文書処理、外部 SaaS 連携 等） |
| カスタムスキル | 組織・プロジェクト独自に登録するスキル |
| MCP サーバー経由のスキル | Model Context Protocol 対応サーバーが提供するツール群 |

### 9.3 主なビルトインスキル

> 表示・利用可能なスキルは、契約プラン・組織設定により異なります。以下は代表例です。

| カテゴリ | スキル例 |
|---|---|
| Web 検索 / 情報取得 | Web 検索、Firecrawl（Web スクレイピング）、Perplexity 検索、Google Trends、Google Scholar |
| 画像生成・編集 | 画像生成（FAL）、Recraft、Ideogram、GPT Image、背景除去・ぼかし |
| 動画 / プレゼン生成 | Kling 動画、Remotion レンダリング、HTML スライド生成、チャート生成 |
| ファイル操作 | 読み取り / 書き込み / 編集、grep、PDF / Word / Excel / PowerPoint 処理、Canvas（描画・注釈） |
| メール / カレンダー | Gmail（送信・検索・ラベル）、Google カレンダー、Outlook、ミーティングスケジューラ |
| チャット / SaaS | Slack（送信・読み取り）、HubSpot、Salesforce、Cybozu Kintone、Jira、Confluence |
| 開発系 | GitHub（リポジトリ検索・PR 一覧・Issue 作成）、汎用 API 呼び出し、Bash（サンドボックス） |
| 業務データ | カスタムオブジェクト（作成・読込・更新・検索・削除）、Salesforce 同期 |
| プラットフォーム連携 | カスタムオブジェクト SQL、Studio ストレージ、Studio ページ、タスクスケジューラ |
| LLM 補助 | コードインタープリタ（E2B サンドボックス）、Gemini マルチモーダル、計算機、時刻取得 |
| メモリ・委譲 | 長期メモリ、会話履歴検索、サブエージェント委譲、ワークフロー実行・管理 |

> **画面プレースホルダー**：`screenshots/09-skills.png`

### 9.4 スキル一覧画面

設定画面 →「スキル」では次の操作が可能です。

- 一覧の参照・検索
- スキルごとの有効・無効切り替え
- バージョン管理
- 入出力スキーマ・実行条件の確認

### 9.5 カスタムスキルの作成

組織・プロジェクト独自のスキルを登録できます。代表的なパターン:

- HTTP API 呼び出し（OpenAPI 互換スキーマでの定義）
- スクリプト（Python / JavaScript）ベースのスキル
- 外部認証（API キー、OAuth）が必要なスキルは [16 章](16-connectors-mcp.md) と組み合わせて設定

詳細な開発手順については、組織管理者・導入元または開発者向けドキュメントをご確認ください。
