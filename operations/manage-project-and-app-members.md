# Project・Appのメンバーを管理する

ProjectやAppを安全に運用するには、利用者を追加するだけでなく、必要な役割だけを付与し、不要になったアクセスを適切に外すことが重要です。この記事では、**管理者がProject・Appの「メンバー」画面で、メンバーを招待し、役割を変更し、削除する手順**を説明します。

Appのメンバー管理も、Appに対応するProjectのメンバー管理として行います。ただし、Appでは利用人数の契約条件や空き状況により、追加時の確認・制限が表示される場合があります。料金や契約上限の判断は、[Appの利用人数・料金・契約上限を確認する](check-app-seats-pricing-and-limits.md)を参照してください。

初期設定全体の順序は、[Appの初期設定を完了する](../use/complete-app-setup.md)を確認してください。組織の所属管理や、役割で可能になる操作の考え方は、[組織・Project・Appの権限を理解する](understand-org-project-app-permissions.md)で扱います。

## 始める前に

- 正しい組織と、対象のProjectまたはAppを確認します。同名の対象がある場合は、説明や利用者も照合します。
- メンバー管理を行う権限があることを確認します。対象を開けても、招待・変更・削除を実行できるとは限りません。
- 追加・変更・削除する人、必要な役割、実施してよい日時を担当者と確認します。
- Appの場合は、追加する人が実際に利用するか、人数条件・契約条件への影響を確認します。
- 削除対象が利用中の業務、共有接続、引き継ぐべき作業を持っていないか確認します。

> 以下はPCのWebブラウザに表示される標準的な画面を前提にしています。メニュー、役割候補、人数の表示、実行できる操作は、組織の設定、権限、Appの契約・構成によって異なります。表示されない機能を別の方法で代用せず、権限を持つ担当者に確認してください。

## メンバー管理で確認する対象

| 対象 | 開き方の目安 | 確認すること |
|---|---|---|
| Project | 対象Projectの「プロジェクト設定」から「メンバー」を開く | そのProjectに参加する人と役割 |
| App | 対象Appを開き、「設定」の「メンバー」を開く | Appの利用者、役割、人数に関する表示 |
| 組織 | 組織のメンバー管理画面 | 組織への所属・招待状況。Project／Appのメンバー管理とは分けて確認する |

Appの「メンバー」画面は、対象Appの設定を管理できる人に表示されます。ProjectとAppでは入口が異なっても、メンバー一覧、招待、役割変更、削除の考え方は共通です。

> **組織に所属していることと、ProjectまたはAppを利用できることは同じではありません。** 追加先を間違えると、必要な人が使えない、または不要な人にアクセスを与えるおそれがあります。操作前後に対象名を確認してください。

## 1. メンバー一覧を開いて現状を確認する

1. 対象のProjectを開き、**「プロジェクト設定」**、**「メンバー」**の順に選びます。Appの場合は対象Appを開き、**「設定」**、**「メンバー」**を選びます。
2. 一覧で、名前、メールアドレス、**「ロール」**、必要に応じて利用人数の表示を確認します。
3. 追加・変更・削除する人を、同姓同名ではなくメールアドレスを含めて特定します。
4. Appで人数に関するバー、案内、警告が表示された場合は、追加操作の前に内容を読みます。

役割候補には「閲覧者」「メンバー」「編集者」「管理者」が表示されることがあります。利用できる候補や実際の権限は設定により異なるため、名称だけで操作可能範囲を推測しないでください。役割の選び方は[組織・Project・Appの権限を理解する](understand-org-project-app-permissions.md)で確認します。

## 2. メンバーを追加・招待する

1. 一覧上部の**「メンバーを招待」**を選びます。
2. 表示された候補から、追加する人を選択します。候補が表示されない場合は、組織への所属状況や検索条件を確認します。
3. **「ロール」**で、担当に必要な役割を選びます。管理作業をしない人を、確認なしに「管理者」にしないでください。
4. Appの場合は、人数条件や料金確認が表示されるか確認します。表示された内容を確認し、承認できる場合のみ**「確認して追加」**または画面の確定操作を選びます。
5. 招待後、一覧を更新し、対象者、役割、Appの場合は人数表示を確認します。

招待できる候補は組織や状態によって変わります。候補にいないことを、メールアドレスの誤りだけが原因と決めつけないでください。また、追加が完了した表示だけでは、その人が業務に必要な外部サービスやApp固有設定まで使えることの証明にはなりません。

> Appの追加で料金確認が表示される場合、確認を確定する前に、対象App・追加人数・表示された料金・更新に関する案内を確認してください。料金をここで推測したり、他のAppと同じ条件だとみなしたりしないでください。

## 3. 役割を変更する

異動や担当変更により、既存メンバーの役割を見直します。変更前に、その人が現在行っている管理・編集・利用作業と、変更後に必要な作業を確認してください。

1. 「メンバー」一覧で対象者の行を開きます。
2. **「ロール」**の現在値と、付与されている役割を確認します。
3. 必要な役割を選択または解除し、画面の保存操作を行います。
4. 保存後、一覧を再表示し、対象者の役割が意図した状態か確認します。
5. 重要な変更は、対象者に変更内容と有効になる業務範囲を連絡します。

最後のProject管理者から管理者権限を外すことはできません。先に別のメンバーへ管理者権限を付与し、反映を確認してから変更してください。自分自身の役割をこの一覧から変更できない場合は、別の管理者に依頼します。

> 役割の保存後に反映に関するエラーが出た場合、保存されていないと決めつけず、一覧を再読み込みして現在の役割を確認してください。同じ変更を繰り返す前に、表示内容とエラーを記録し、管理担当者へ相談します。

## 4. メンバーを削除する

削除は、対象ProjectまたはAppへのアクセスを外す操作です。組織そのものからの削除、Appのアンインストール、Projectやリソースの削除とは異なります。

1. 対象者が正しいこと、引き継ぎや停止が必要な作業がないことを確認します。
2. 「メンバー」一覧で対象者の操作を開き、**「削除」**を選びます。
3. 確認画面で、削除する人と対象ProjectまたはAppを再確認します。
4. **「削除する」**を選び、処理を確定します。
5. 一覧を更新し、対象者がメンバーとして表示されず、想定どおりアクセスが外れたことを確認します。

削除したメンバーのProjectまたはAppへのアクセスは取り消されますが、Projectやリソース自体を削除する操作ではありません。最後のProject管理者は削除できません。管理者の退任・退出を伴う場合は、先に後任の管理者を決めて権限を付与します。

> 自分自身を一覧から削除することはできません。Appから自分が退出する必要がある場合は、表示される**「このアプリから退出する」**を使い、最後の管理者ではないことを確認してください。ProjectとAppで退出可能な条件が異なる場合があるため、削除操作で代用しないでください。

## App固有：人数・シートへの影響を確認する

Appでは、メンバーの追加・削除が利用人数やシートの状態に関係する場合があります。画面に**「アプリ利用ユーザー数」**、利用上限、料金確認、空きシートに関する案内が出た場合は、以下を確認します。

| 操作 | 確認すること | 対応 |
|---|---|---|
| 追加 | 空きや上限、料金確認の表示があるか | 契約・承認条件を確認してから確定する |
| 上限到達 | 追加が無効になっていないか、画面に案内があるか | 購入権限を持つ組織管理者またはアカウント担当者へ確認する |
| 削除 | その人が利用を終えているか | 削除後に人数表示とアクセスの状態を確認する |
| 契約・料金の変更 | 購入数、更新料金、返金などへの影響 | この画面だけで判断せず、[Appの利用人数・料金・契約上限を確認する](check-app-seats-pricing-and-limits.md)を確認する |

画面上の人数表示は、対象Appの利用者数・契約状態を確認するための手がかりです。すべてのAppで同じシート制や料金確認が表示されるわけではありません。表示がないことを、人数条件や費用がない根拠にはしないでください。

## うまくいかない場合

| 状況 | 確認・対応 |
|---|---|
| 「メンバー」や「設定」が表示されない | 正しいProject／Appか、設定を管理する権限があるか、組織の設定で機能が利用可能かを確認する |
| 「メンバーを招待」を選べない | 招待権限、対象Appの状態、人数上限・契約上の制限に関する案内を確認する |
| 追加したい人が候補にいない | 組織への所属、候補の検索結果、対象Project／Appを確認する。組織への招待が必要な場合は組織管理者へ依頼する |
| 役割を変更できない | 変更権限、選べる役割、最後の管理者を変更しようとしていないかを確認する |
| 削除できない | 自分自身や最後の管理者ではないか、削除権限があるかを確認する。必要なら後任へ管理者権限を付与してから再確認する |
| Appの追加時に料金・人数の確認が出る | 対象App、追加対象、表示内容、承認権限を確認する。料金・契約の詳細は[Appの利用人数・料金・契約上限を確認する](check-app-seats-pricing-and-limits.md)を確認する |
| 保存後の状態が分からない | 一覧を再読み込みし、対象者・役割・人数表示を確認する。同じ操作を連続で確定しない |

問い合わせる際は、組織名、対象のProjectまたはApp、対象者のメールアドレス、操作日時、操作した画面、表示されたメッセージ、現在の一覧表示を伝えます。パスワード、APIキー、Secretの値などの機密情報は含めないでください。
