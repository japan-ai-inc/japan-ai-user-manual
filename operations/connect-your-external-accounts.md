# 自分の外部アカウントを接続する

外部サービスを使うAgentやWorkflow、またはそれらを含むAppでは、利用者本人の認証が必要になる場合があります。この記事では、**自分のアカウントで個人接続を作成し、接続状態を確認して、必要なときに解除・再認証する方法**を説明します。

個人接続は、本人が利用する外部サービスへの認証です。ProjectやApp全体で使う共有接続、APIキーなどのSecretとは目的と管理者が異なります。自分の接続ができたことだけで、他の利用者やApp共通の設定も完了したとは判断しないでください。使い分けは[個人接続・共有接続・Secretを選ぶ](choose-personal-shared-connections-and-secrets.md)を参照してください。

導入済みAppから利用を始める場合は、[導入済みAppを開いて利用を始める](../use/open-installed-app.md)、共有されたProjectから利用する場合は、[共有されたProjectで利用を始める](../use/start-with-shared-project.md)を先に確認します。

## 始める前に

| 確認事項 | 確認する内容 |
|---|---|
| 利用先 | 対象の組織、AppまたはProject、利用するAgent・Workflow・業務画面 |
| 接続先 | 接続が求められた外部サービスと、業務で使用を許可された自分のアカウント |
| 必要性 | 画面に「接続が必要」と表示されたか、利用する機能の案内で本人の認証が必要とされているか |
| 影響範囲 | 接続後にAgentやWorkflowが参照・実行する可能性があるデータ、送信先、更新先 |
| 問い合わせ先 | AppまたはProjectを案内した担当者。共有設定が必要な場合の管理者 |

> 表示される接続先、設定の入口、操作できる範囲は、組織の提供条件、権限、App・Projectの構成によって異なります。画面に個人接続の案内がない場合、接続が不要であることも、共有接続を使うこともあります。必要な設定を推測して追加しないでください。

> パスワード、APIキー、認証トークンを、チャット・問い合わせ・スクリーンショットへ貼り付けないでください。OAuthなど外部サービスの認証画面が開く場合も、サービス名とサインインするアカウントを確認してから進めます。

## 個人接続を行う場所

個人接続は、主に次の場所から始めます。どちらの入口でも、対象のApp・Projectと接続先サービスが案内に合うことを確認してください。

| 入口 | 使う場面 | 進め方 |
|---|---|---|
| Appの接続要件 | Appを開いたとき、または利用中に個人の認証を求められた場合 | App内の「設定」や表示された接続案内から、必要な「個人用のコネクタ」を選びます。 |
| Projectの「コネクタ設定」 | Project内で接続を確認・追加する必要がある場合 | 「コネクタ設定」を開き、「個人のコネクタ」を確認します。追加できる場合は「新しいコネクタ」から「個人用コネクタ」を選びます。 |
| Agent・Workflowの実行時の案内 | 実行時に認証情報が求められた場合 | 表示された「認証情報を接続」または接続案内から、指定されたサービスだけを接続します。 |

「コネクタ設定」に「個人のコネクタ」が表示されない、または「新しいコネクタ」が使えない場合は、利用者が設定できない構成や、機能が提供されていない可能性があります。共有接続や権限の対応が必要か、担当者へ確認してください。

## 1. 必要な個人接続を選ぶ

1. 利用するAppまたはProjectを開き、接続が必要と表示された機能を確認します。
2. 「設定」または案内された入口から「コネクタ設定」を開きます。App内で接続画面が表示された場合は、その画面から進めます。
3. 「個人用のコネクタ」を選びます。追加画面では「個人用コネクタ」を選択します。
4. 一覧から、案内された外部サービスを選びます。GoogleやMicrosoftなど、利用できるサービスだけが表示される場合があります。
5. サービス名、接続するアカウント、利用目的を確認して「連携」または表示された接続操作を選びます。

外部サービスの認証画面に移動する場合は、そのサービスで本人がサインインし、要求される権限を確認して許可します。求められる権限の内容や画面は接続先ごとに異なります。業務で許可されていないアカウント、他者のアカウント、テスト用か不明なアカウントでは接続しないでください。

> 「プロジェクト用コネクタ」や「共有接続」は個人接続とは別の設定です。通常の利用者が自分の認証を設定する目的で選ばないでください。App共通の接続が「未設定」「無効」などの場合は、管理者に対応を依頼します。

## 2. 認証を完了し、接続状態を確認する

認証が終わると、元の画面または「コネクタ設定」に戻ります。次の順で確認します。

1. 「個人のコネクタ」に、選択したサービスの接続が表示されることを確認します。
2. Appの要件画面がある場合は、個人用の状態が「接続済み」になったことを確認します。
3. 接続の詳細を開ける場合は、「アカウント」「接続タイプ」「最終認証日時」を確認します。「接続タイプ」は「個人接続」であることを確認します。
4. 案内されたAgent、Workflow、またはAppの業務画面へ戻り、許可された小さな操作で利用できるか確認します。

Appの要件画面には、「接続済み」のほかに「共有コネクタを利用」と表示される場合があります。この場合、本人の個人接続を追加すべきか、共有設定をそのまま利用する想定かを担当者に確認します。「接続が必要」のままなら、認証が完了していない、別の接続先を選んだ、または接続状態を読み込めていない可能性があります。

**接続状態の表示と、実際の業務処理の成功は別です。** たとえば、Agentが外部データを参照する、Workflowがメール送信やデータ更新を行う場合は、対象・送信先・更新先と結果を確認してください。実行済みか不明な処理は、同じ操作をすぐに繰り返さないでください。

## Agent・Workflowでの使われ方

個人接続は、接続した外部サービスを必要とする機能で使用されます。すべてのAgentやWorkflowが自動的に自分の接続を使うわけではありません。

| 利用するもの | 個人接続との関係 | 利用前に確認すること |
|---|---|---|
| Agent | Agentに設定された外部ツールやコネクタが、本人の認証を必要とする場合に使われます。 | Agent名、参照・実行するサービス、データの範囲 |
| Workflow | Workflow内の外部サービスを使う処理が、本人の認証を必要とする場合に使われます。 | 実行対象、送信・更新・保存の有無、実行結果 |
| Appの業務画面 | 画面の裏側でAgentやWorkflowなどが外部サービスを使う場合に、個人接続を求められることがあります。 | 画面の案内と、必要な接続が個人用か共有用か |

> 接続したアカウントの権限で外部サービスにアクセスする可能性があります。接続しただけで操作が実行されるとは限りませんが、AgentやWorkflowを実行する前に、対象データと外部への影響を確認してください。

## 接続を解除・再接続する

アカウントを変更する、利用を終える、認証が無効になった場合は、対象の個人接続を確認して対応します。

### 接続を解除する

1. 「コネクタ設定」の「個人のコネクタ」から、解除する接続を開きます。
2. サービス名、アカウント、接続タイプが「個人接続」であることを確認します。
3. 「連携解除」を選び、確認画面でも対象を確認して「連携解除」を実行します。
4. 一覧またはAppの要件画面で、状態が変わったことを確認します。

解除すると、その接続に依存するAgent・Workflow・Appの機能が利用できなくなる場合があります。不要な接続だけを解除し、共有接続や他の利用者の接続を自分の判断で変更しないでください。

### 再接続・再認証する

認証の期限切れ、外部サービス側の変更、誤ったアカウントでの接続などで利用できない場合は、まず対象の接続と表示されたエラーを確認します。画面に「再認証」や再接続の案内が表示される場合は、案内に従い、正しいアカウントで認証をやり直します。再認証の入口がない場合は、接続を追加・解除する前に担当者へ確認してください。

接続が失効したときや担当者が変わるときの判断・引き継ぎは、[接続の失効・担当者変更に対応する](handle-expired-connections-and-owner-changes.md)で扱います。

## うまくいかない場合

| 状況 | 最初に確認すること |
|---|---|
| 「接続が必要」と表示される | 対象のApp・Project、必要なサービス、個人接続が求められているか、正しい組織で開いているか |
| サービスが一覧にない | Appの要件、提供条件、権限。表示されないサービスを自己判断で別の方法で接続しない |
| 認証画面で失敗・戻ってこない | サインインしたアカウント、外部サービス側の認証条件、表示されたエラー。認証情報は共有しない |
| 「接続済み」にならない | 認証後に元の画面を開き直す。別サービス・別アカウント・個人用ではない接続を選んでいないか確認する |
| 接続済みだがAgent・Workflowが失敗する | 実行権限、外部サービス側のアクセス権、対象データ、共有接続の要否、実行時のエラー |
| 接続を変更・解除できない | 接続タイプ、操作権限、Appの構成。共有接続なら管理者へ依頼する |

解決しない場合は、組織名、AppまたはProject名、対象のAgent・Workflow・画面、接続先サービス、行った操作、発生日時、表示メッセージを担当者へ伝えます。パスワード、APIキー、トークン、認証画面の不要な情報は送らないでください。

- [ ] 「個人のコネクタ」またはAppの要件画面で、状態を確認した。
- [ ] 接続の詳細で、アカウントと接続タイプが意図した「個人接続」か確認した。
