# Appの利用人数・料金・契約上限を確認する

Appのメンバーを追加・削除したり、利用を終了したりする前に、**利用人数、契約上限、表示される料金確認**を分けて確認します。この記事は、App管理者が導入済みAppの人数変更・終了について料金影響を判断するための案内です。

メンバーを招待・ロール変更・削除する具体的な操作は、[Project・Appのメンバーを管理する](manage-project-and-app-members.md)を参照してください。App全体を終了する操作と、データ・利用者への影響は[Appをアンインストールする](../use/uninstall-app.md)で確認します。機能別の制限や提供条件の探し方は、[制限・提供条件の索引](limits-and-availability-index.md)で扱います。

## この記事の範囲

ここで扱うのは、Appの利用者数に関わる表示と、画面に表示されるシート料金です。実行で消費するクレジット、外部サービスの契約、すでに確定した請求、App以外の料金までを、この画面の案内だけで判断しないでください。

また、すべてのAppに人数課金、シートの購入・調整、同じ料金確認があるわけではありません。料金や契約条件の表示がないことを、無料であることや費用が発生しないことの根拠にはできません。

> 本記事に金額を記載しません。料金が表示される場合は、対象App・変更後の人数・今回の料金・次回更新の案内を、実際の画面で確認してください。表示された料金を他のAppや別の組織へ流用しないでください。

## まず区別する3つの数

Appの人数に関する表示は、少なくとも次の3つを混同しないようにします。

| 確認対象 | 画面での表示例 | 意味と判断 |
|---|---|---|
| 現在の利用者 | 「メンバー」、または「メンバー数」 | Appの利用対象になっている人です。削除するとアクセスを外します。 |
| 契約上限 | 「アプリ利用ユーザー数」 | このAppの契約ユーザー数です。上限に達した場合は、追加前に対応が必要です。 |
| 購入・使用・空きシート | 「購入済み」「使用中」「空き」 | 人数課金のAppで表示される場合があります。利用者を削除して空きができても、購入数・更新料金が自動で変わるとは限りません。 |

「アプリ利用ユーザー数」は、Appの**「設定」→「メンバー」**で確認します。契約上限があるAppでは、利用状況と上限をバーで表示し、補足には「このアプリの契約ユーザー数です。変更はアカウント担当者にお問い合わせください。」と案内されます。招待画面では、**「アプリ利用ユーザー数：上限○人（残り○人）」**の形で、上限と残数が表示される場合があります。

> 組織の所属人数、Projectの一般的なメンバー上限、Appの「アプリ利用ユーザー数」は別の条件です。Appの招待画面にApp固有の上限が表示される場合は、そちらを優先して確認します。

### 無料Appを組織全員へ開放する場合

無料Appでは、必要なApp管理・招待権限を持つ管理者が、組織の全メンバーに開放できる場合があります。開放されたAppは、アクティブな組織メンバーが最初に開いたときに利用対象へ追加されます。開放を停止しても、すでに追加されたメンバーは自動削除されません。**シート課金のAppではこの開放設定は利用できません。** 個別の削除・ロール変更は[Project・Appのメンバーを管理する](manage-project-and-app-members.md)に従ってください。

## 1. 追加前に、上限と対象者を確認する

1. 正しい組織で対象Appを開き、**「設定」**から**「メンバー」**を開きます。
2. 一覧で現在の利用者と、その人が本当にAppを利用するかを確認します。
3. **「アプリ利用ユーザー数」**、または招待画面の上限・残数を確認します。
4. 追加する人の数が残数を超えないか確認します。残数より多い人を選ぶと、追加できる人数に関する警告が表示され、招待を進められない場合があります。
5. 上限到達の案内が出た場合は、削除だけで解消できるか、契約ユーザー数の変更が必要かを確認します。画面の案内に従い、アカウント担当者または購入権限を持つ組織管理者へ依頼してください。

「メンバー上限を確認しています…」または取得できない旨が表示される間は、人数条件を満たすと判断しないでください。時間をおいて再表示しても確認できない場合は、追加を確定せず、対象App、追加予定人数、表示内容を添えて管理担当者へ確認します。

## 2. 料金確認が表示されたときに同意する

人数課金のAppでは、メンバー追加の前に**「メンバー追加の料金確認」**が表示されることがあります。この画面は、追加によって料金が発生する場合に、今回の料金と次回更新を確認するためのものです。

1. **「メンバーを招待」**で追加対象と**「ロール」**を選びます。役割と招待の詳細は[Project・Appのメンバーを管理する](manage-project-and-app-members.md)を参照してください。
2. 料金確認が出た場合は、対象App、追加対象、今回の料金、**「次回更新」**の日付・月額を確認します。日付は日本時間で表示されます。
3. 料金の承認権限と予算を確認します。表示内容に同意できない、または判断できない場合は**「キャンセル」**し、追加しません。
4. 同意できる場合に限り、**「確認して追加」**を選びます。確認を取り消すと、当該の追加処理には進みません。
5. 追加後は一覧を更新し、対象者、ロール、利用人数の表示を確認します。

料金確認が出ない場合も、追加が常に無償であるとは限りません。一方、料金確認が出た場合でも、画面に表示された今回の料金と次回更新以外の費用まで判断できるわけではありません。料金または見積もりの変更が表示された場合は、古い確認を使わず、最新の料金を確認してから改めて同意します。

> 追加処理の途中で権限設定に失敗しても、メンバーが追加済みとなり、有料Appでは課金対象になる旨の案内が表示される場合があります。同じ人を繰り返し追加する前に、メンバー一覧と表示メッセージを確認してください。再試行に追加料金がかからないという案内が表示される場合も、その対象・状態を確認してから操作します。

## 3. メンバーを削除した後の料金影響を判断する

利用を終えた人を削除すると、その人のAppへのアクセスは外れます。人数課金のAppでは、削除によりシートが空き、別のメンバーへ割り当てられる場合があります。

ただし、**メンバーを削除しただけでは、購入数や更新料金は変わりません。** 購入数を減らす必要がある場合は、空きシートを確認したうえで**「シートを調整」**を開き、変更後の購入シート数を指定します。使用中のシート数より少ない数には変更できません。

1. [Project・Appのメンバーを管理する](manage-project-and-app-members.md)に従い、削除対象の業務・引き継ぎ・アクセスへの影響を確認してからメンバーを削除します。
2. 「購入済み」「使用中」「空き」が表示される場合は、削除後の空きを確認します。
3. 購入数を減らす場合は**「シートを調整」**を選び、変更後の数と表示される料金を確認します。
4. **「表示された料金と、このシート数での毎月の更新に同意します。」**という確認を読み、同意できる場合のみ**「シート数の変更を確定」**を選びます。
5. 完了後、購入数・使用中・空きと、次回更新の案内を再確認します。

購入数を減らすと次回の更新料金は下がりますが、当月分は返金されません。当月に支払い済みのシート数へ戻す場合は、追加料金がかからないと案内されます。削除後すぐに返金される、過去の請求が取り消される、外部サービスの費用も下がる、とは扱わないでください。

## 4. Appを終了する場合

アンインストールは、メンバーを一人削除する操作とは異なります。終了前に利用者、データ、外部サービス、定期実行などの影響を確認し、手順は[Appをアンインストールする](../use/uninstall-app.md)に従います。

シート課金のAppをアンインストールする場合は、アンインストール確認画面と契約・料金の案内を別に確認してください。アンインストールだけで、更新、当月分の返金、未払い分、すでに確定した費用、他のApp、外部サービスの契約まで取り消されるとは解釈しません。シートや更新の扱いを画面で確認できない場合は、管理者またはJAPAN AIサポートへ確認します。

アンインストール後の再利用、残った契約上限や料金の扱いを画面だけで確定できない場合は、完了と判断する前にアカウント担当者またはJAPAN AIサポートへ確認してください。

## よくある誤解

| 誤解 | 正しい確認 |
|---|---|
| メンバーを削除すれば、すぐ料金が下がる | 削除では空きシートになるだけです。購入数を減らす操作と、次回更新の案内を別に確認します。 |
| 上限に達したら、組織のメンバーを削除すればよい | Appの利用者、組織の所属、Projectのメンバーを区別します。影響範囲を確認せずに削除しません。 |
| 料金確認が出なければ、費用はない | 表示がないことだけでは判断できません。契約条件や別の費用は担当者へ確認します。 |
| アンインストールすれば更新も当月分も止まる | アンインストールと契約・料金の扱いは別に確認します。画面に表示された更新・返金の案内を確認し、不明なら管理者またはJAPAN AIサポートへ問い合わせます。 |

## 確認できない場合

| 状況 | 確認・対応 |
|---|---|
| 「アプリ利用ユーザー数」や人数バーが見つからない | 正しいAppの「設定」→「メンバー」を開いているか、設定を確認できる権限があるかを確認します。表示がないことを無制限・無料の根拠にしません。 |
| 上限到達で追加できない | 追加対象、残数、削除予定者、契約ユーザー数の変更が必要かを確認します。アカウント担当者または購入権限を持つ組織管理者へ依頼します。 |
| 料金確認の内容を承認できない | 「キャンセル」して追加・シート数変更を確定しません。対象App、人数、今回の料金、次回更新の案内を添えて承認者へ確認します。 |
| 削除後も料金表示が変わらない | 購入数と利用者数は別です。空きシート、購入数、更新料金を確認し、必要なら「シートを調整」で見積もりを確認します。 |
| 終了後の料金が不明 | Appのアンインストール確認画面の案内と[Appをアンインストールする](../use/uninstall-app.md)を確認します。対象外の契約や確定済み費用は、担当者またはサポートへ確認します。 |

問い合わせには、組織名、対象App、現在の利用人数・表示された上限、追加・削除・終了の予定、表示された今回の料金・次回更新の案内、操作日時を添えます。クレジットカード情報、認証情報、個人情報を必要以上に送らないでください。

- [ ] 追加人数が残数・契約上限に収まるか確認した
- [ ] 料金確認が出た場合、今回の料金と次回更新を確認し、承認を得た
- [ ] メンバー削除と購入数の変更を別の操作として確認した
- [ ] 購入数を減らす場合、使用中のシート数と表示料金を確認して同意した
