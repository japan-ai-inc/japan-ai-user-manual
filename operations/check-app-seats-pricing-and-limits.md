# Appの利用人数・料金・契約上限を確認する

Appのメンバーを追加・削除したり、利用を終了したりする前に、**利用人数、契約上限、表示される料金確認**を確認します。この記事は、App管理者が導入済みAppの人数変更・終了について料金影響を判断するための案内です。

メンバーを招待・ロール変更・削除する具体的な操作は、[Project・Appのメンバーを管理する](manage-project-and-app-members.md)を参照してください。App全体を終了する操作と、データ・利用者への影響は[Appをアンインストールする](../use/uninstall-app.md)で確認します。機能別の制限や提供条件の探し方は、[制限・提供条件の索引](limits-and-availability-index.md)で扱います。

## 要点

| 項目 | 決まり |
|---|---|
| 課金の単位（有料App） | 2026-09-17以降、**有効メンバー数**で課金されます。**月額 ＝ 単価 × 有効メンバー数** です。 |
| 月次更新 | 更新時に、その時点の有効メンバー数で自動的に精算されます。購入数を手動で調整する操作（シート調整）はありません。 |
| メンバーを追加したとき | 追加前に「メンバー追加の料金確認」が表示され、同意すると追加されます。 |
| メンバーを削除したとき | 有効メンバー数が減るため、**次回の更新料金が下がります**。当月分は返金されません。 |
| Appをアンインストールしたとき | 確認画面に「今後の更新料金は発生しません。当月分は返金されません。」と表示されます。 |
| インストールした人・自分で参加した組織管理者 | 自動でApp管理者になり、有料Appでは有効メンバー1人として数えられます。 |

## この記事の範囲

ここで扱うのは、Appの利用者数に関わる表示と、画面に表示されるAppの料金です。実行で消費するクレジット、外部サービスの契約、すでに確定した請求、App以外の料金は、この画面だけでは判断できません。クレジットは[実行消費と利用状況を確認する](check-execution-consumption-and-usage.md)で確認します。

すべてのAppが有料ではありません。無料Appでは料金確認は表示されません。

> 本記事に単価は記載しません。料金は、対象App・変更後の人数・今回の料金・次回更新の案内を、実際の画面で確認してください。

## 人数に関する2つの表示

| 確認対象 | 画面での表示例 | 意味 |
|---|---|---|
| 有効メンバー | 「メンバー」、または「メンバー数」 | Appの利用対象になっている人です。有料Appでは、この人数が月額の計算に使われます。削除するとアクセスが外れ、次回更新から料金の対象外になります。 |
| 契約上限 | 「アプリ利用ユーザー数」 | このAppの契約ユーザー数です。上限に達した場合は、追加前に対応が必要です。 |

「アプリ利用ユーザー数」は、Appの**「設定」→「メンバー」**で確認します。契約上限があるAppでは、利用状況と上限をバーで表示し、補足には「このアプリの契約ユーザー数です。変更はアカウント担当者にお問い合わせください。」と案内されます。招待画面では、**「アプリ利用ユーザー数：上限○人（残り○人）」**の形で、上限と残数が表示されます。

> 組織の所属人数、Projectのメンバー、Appの「アプリ利用ユーザー数」は別の条件です。Appの招待画面にApp固有の上限が表示される場合は、そちらを優先して確認します。

### 無料Appを組織全員へ開放する場合

無料Appでは、App管理者が「組織の全メンバーに公開」を有効にできます。開放されたAppは、アクティブな組織メンバーが最初に開いたときにメンバーとして追加されます。開放を停止しても、すでに追加されたメンバーは自動削除されません。**有料Appではこの設定は利用できません。** 個別の削除・ロール変更は[Project・Appのメンバーを管理する](manage-project-and-app-members.md)に従ってください。

## 1. 追加前に、上限と対象者を確認する

1. 正しい組織で対象Appを開き、**「設定」**から**「メンバー」**を開きます。
2. 一覧で現在の利用者と、その人が本当にAppを利用するかを確認します。有料Appでは、追加した人数分だけ月額が増えます。
3. **「アプリ利用ユーザー数」**、または招待画面の上限・残数を確認します。
4. 追加する人の数が残数を超えないか確認します。残数より多い人を選ぶと、追加できる人数に関する警告が表示され、招待を進められません。
5. 上限に達している場合は、利用しない人の削除で解消できるか、契約ユーザー数の変更が必要かを判断します。契約ユーザー数の変更はアカウント担当者へ依頼してください。

「メンバー上限を確認しています…」または取得できない旨が表示される間は、追加を確定しないでください。時間をおいて再表示しても表示されない場合は、対象App、追加予定人数、表示内容を添えて管理担当者へ問い合わせます。

## 2. 料金確認が表示されたときに同意する

有料Appでは、メンバー追加の前に**「メンバー追加の料金確認」**が表示されます。この画面で、今回の料金と次回更新を確認します。

1. **「メンバーを招待」**で追加対象と**「ロール」**を選びます。役割と招待の詳細は[Project・Appのメンバーを管理する](manage-project-and-app-members.md)を参照してください。
2. 対象App、追加対象、今回の料金、**「次回更新」**の日付・月額を確認します。日付は日本時間で表示されます。
3. 料金の承認権限と予算を確認します。同意できない場合は**「キャンセル」**し、追加しません。
4. 同意できる場合に限り、**「確認して追加」**を選びます。
5. 追加後は一覧を更新し、対象者、ロール、利用人数の表示を確認します。

料金が変更された旨が表示された場合は、古い確認を使わず、最新の料金を確認してから改めて同意します。

> 追加処理の途中で権限設定に失敗しても、メンバーは追加済みとなり、有料Appでは課金対象になる旨が表示されることがあります。同じ人を繰り返し追加する前に、メンバー一覧と表示メッセージを確認してください。

## 3. メンバーを削除した後の料金

有料Appの月額は **単価 × 有効メンバー数** で、月次更新時にその時点の有効メンバー数で自動的に精算されます。

- 利用を終えた人を削除すると、その人のAppへのアクセスが外れ、**次回の更新料金が下がります**。購入数を別に減らす操作は不要です（シートを調整する画面はありません）。
- 当月分は返金されません。
- 過去の請求の取り消しや、外部サービスの費用の変更にはなりません。

手順：

1. [Project・Appのメンバーを管理する](manage-project-and-app-members.md)に従い、削除対象の業務・引き継ぎ・アクセスへの影響を確認してからメンバーを削除します。
2. 一覧で有効メンバー数を確認します。次回更新の月額は、更新時点の有効メンバー数で計算されます。

## 4. Appを終了する場合

アンインストールは、メンバーを一人削除する操作とは異なります。終了前に利用者、データ、外部サービス、定期実行などの影響を確認し、手順は[Appをアンインストールする](../use/uninstall-app.md)に従います。

有料Appをアンインストールすると、確認画面に**「今後の更新料金は発生しません。当月分は返金されません。」**と表示され、そのとおりに処理されます。他のApp、外部サービスの契約、すでに確定した請求には影響しません。

## よくある誤解

| 誤解 | 実際 |
|---|---|
| メンバーを削除しても料金は変わらない | 有効メンバー数で課金されるため、削除すると次回の更新料金が下がります。当月分は返金されません。 |
| 購入数を減らすには「シートを調整」が必要 | シート調整の操作はありません。月次更新時に有効メンバー数で自動的に精算されます。 |
| 上限に達したら、組織のメンバーを削除すればよい | Appの利用者、組織の所属、Projectのメンバーは別です。Appのメンバーから、利用しない人を削除します。 |
| アンインストールすれば当月分も返金される | 今後の更新料金は発生しませんが、当月分は返金されません。 |

## うまくいかない場合

| 状況 | 確認・対応 |
|---|---|
| 「アプリ利用ユーザー数」や人数バーが見つからない | 正しいAppの「設定」→「メンバー」を開いているか、App管理者であるかを確認します。 |
| 上限到達で追加できない | 利用しない人を削除するか、アカウント担当者に契約ユーザー数の変更を依頼します。 |
| 料金確認の内容を承認できない | 「キャンセル」して追加を確定しません。対象App、人数、今回の料金、次回更新の案内を添えて承認者へ確認します。 |
| 削除したのに当月の請求が変わらない | 削除は次回更新から反映され、当月分は返金されません。次回更新の月額を確認します。 |
| 終了後の料金が不明 | Appのアンインストール確認画面の案内と[Appをアンインストールする](../use/uninstall-app.md)を確認します。それ以外の契約や確定済み費用は、アカウント担当者またはJAPAN AIサポートへ問い合わせます。 |

問い合わせには、組織名、対象App、現在の利用人数・表示された上限、追加・削除・終了の予定、表示された今回の料金・次回更新の案内、操作日時を添えます。クレジットカード情報、認証情報、個人情報を必要以上に送らないでください。

## チェックリスト

- [ ] 対象が正しい組織・Appであることを確認した
- [ ] Appの「メンバー」で有効メンバーと「アプリ利用ユーザー数」を確認した
- [ ] 追加人数が残数・契約上限に収まるか確認した
- [ ] 料金確認で今回の料金と次回更新を確認し、承認を得た
- [ ] 利用しない人を削除すると次回更新から月額が下がること（当月分は返金されないこと）を理解した
- [ ] 有料Appを終了する場合、[Appをアンインストールする](../use/uninstall-app.md)に従って影響を確認した
