# Skillの仕様・制限

Skillは、特定のタスクで再利用する指示・コード・リソースをまとめたフォルダです。Agentは依頼に応じてSkillを利用しますが、Skillを作成・保存しただけでは、既存のAgentへ自動追加されません。この記事では、Skill固有の前提、入力形式、共有範囲、上限を確認します。作成と利用の手順は[Skillを作成して利用する](create-and-use-skills.md)を参照してください。

- 関連記事：[Skillを作成して利用する](create-and-use-skills.md)
- 関連記事：[制限・提供条件の索引](../operations/limits-and-availability-index.md)

## この記事の範囲

ここでは、画面上の「スキルビルダー」で扱うSkillのファイル構成、`SKILL.md`のfrontmatter、アップロード、ツール、公開範囲、Agentへの追加、編集権限を説明します。Agentの指示・認証・追加後の動作確認は[Agentにツール・Skill・Datasetを設定する](configure-agent-tools-skills-datasets.md)、設計・作成手順は[Skillを作成して利用する](create-and-use-skills.md)を参照してください。

表示される項目、候補、操作可否は、組織・Project、権限、提供状態によって異なります。本記事の数値は、確認できた実装上の入力検証を対象とし、契約上限や将来の提供条件を示すものではありません。

## 仕様・前提

### `SKILL.md`とファイル構成

| 項目 | 仕様 | 補足 |
|---|---|---|
| 必須ファイル | Skillのルートに`SKILL.md`が必要です。 | ない場合は保存・取り込みの対象にできません。本文には、目的、判断条件、手順、出力形式、例外時の対応を記載します。 |
| frontmatter | `SKILL.md`の先頭にYAML形式のfrontmatterが必要です。 | `---`で囲みます。形式が読めない場合は、保存前に修正します。 |
| `name` | 必須です。画面上の「スキルID」に対応し、3〜128文字です。 | 英小文字、数字、アンダースコアのみを使います。ハイフンや空白、大文字は使えません。既存のスキルIDとの重複も避けます。 |
| `description` | 必須です。 | 空欄にせず、何をするSkillか、対象と成果物が分かる説明にします。説明の最大文字数は、この確認範囲の実装からは確認できません。 |
| 任意項目 | `display_name`、`agent_prompt`、`tools`をfrontmatterに記載できます。 | `display_name`は表示名、`tools`はツール名の一覧です。画面の「表示名」「説明」「ツール」と`SKILL.md`は同期して扱われるため、片方だけを変更した後は内容を確認します。 |
| 補助ファイル・フォルダ | `SKILL.md`と同じフォルダ配下に、テンプレート、参照資料、スクリプトなどを置けます。 | 本文から参照するファイル名・相対位置と実際の構成を一致させます。不要な認証情報や機密情報は含めません。 |

最小構成の例です。`description`には、利用場面と結果を具体的に書きます。

```md
---
name: meeting_summary
display_name: 会議要約
description: 会議メモから決定事項、担当者、期限を整理する
---

# 手順
...
```

### 「スキルをアップロード」とフォルダの扱い

| 項目 | 仕様 | 補足 |
|---|---|---|
| 取り込み方法 | 「スキルをアップロード」では「ZIPファイルを選択」、ドラッグ＆ドロップ、「フォルダを選択」が使えます。 | フォルダを選択またはフォルダをドロップした場合も、画面でZIP化してから取り込みます。ZIP以外の単一ファイルは取り込めません。 |
| ZIP内の`SKILL.md` | `SKILL.md`を含むZIPが必要です。 | 画面の検証では、最上位または1つの親フォルダ直下の`SKILL.md`を確認します。エラー時は、ZIPを開いて配置を見直します。 |
| 圧縮ファイルの入れ子 | Skill用ZIPの中に別の圧縮ファイルを含めることはできません。 | ZIP爆弾対策です。素材が圧縮されている場合は、必要な内容を展開してからSkillに含めます。 |
| パス | 親フォルダの外を指すパスや絶対パスは受け付けられません。 | 取り込み前に、ZIPの中に意図しないファイルやパスがないか確認します。 |
| 表示・編集 | ファイル一覧で内容を確認し、`SKILL.md`を編集できます。 | 過去バージョンを表示している間は保存できません。「現在」のバージョンに戻してから更新します。 |

### ツール、公開範囲、Agentへの追加

| 項目 | 仕様 | 補足 |
|---|---|---|
| 「ツール」 | 「ツール」で選択したツールは、そのSkillで使用できるようになります。 | 必要なものだけを選びます。Skillへ記載しただけでは、接続先の認証や操作権限は設定されません。 |
| 公開範囲「組織」 | 組織内で利用するSkillに設定する範囲です。 | 組織内で見せてよい指示、補助ファイル、選択ツールだけを含めます。 |
| 公開範囲「非公開」 | 自分のみで利用するSkillに設定する範囲です。 | 他のユーザーは非公開Skillを利用できません。他ユーザーが作成した非公開Skillを、自分のAgentへ追加することもできません。 |
| Agentへの追加 | Agent編集画面の「プラグイン」から「追加」を選び、「スキル」の候補を追加します。 | Skillの作成・更新と、Agentへの追加は別の操作です。追加後にAgentの設定へ表示されていることを確認します。 |
| Projectへリンクした外部Skill | Project内で利用する外部Skillは、画面に表示される候補からリンクします。 | Project外からリンクしたSkillはProject内では読み取り専用です。内容を変える必要がある場合は作成元を更新します。 |
| 組織へ公開したAgent | 組織に公開したAgentに非公開Skillが設定されていると、公開範囲の変更を促す警告が表示されます。 | 警告を消すためだけに「組織」へ変更せず、Skillの内容を共有してよいか確認します。Agentの共有とSkillの公開範囲は別です。 |
| 作成・編集権限 | Skillの作成・編集には、エディターまたは管理者権限が必要です。 | 閲覧・利用できることと、作成・編集できることは別です。操作が表示されない、保存できない場合は管理者へ確認します。 |

## 上限・制限値

次の値は、Skillの入力・ZIP・アイコンの検証で確認できる制限です。「以下」は上限値を含み、「超える」と拒否対象になります。フォルダを選んだ場合もZIP化後の検証対象です。

| 項目 | 上限・制限値 | 条件・補足 |
|---|---|---|
| ZIPファイルの圧縮後サイズ | 20MB以下 | 「ZIPファイルを選択」、ドラッグ＆ドロップ、フォルダから作成したZIPに適用されます。 |
| ZIP内のファイル数 | 1,000個以下 | ディレクトリ自体を除くファイル数です。 |
| 展開後の合計サイズ | 100MB以下 | ZIP内のファイルを展開した合計に適用されます。 |
| 展開後の個別ファイルサイズ | 50MB以下 | 画面側のZIP内容検証で適用されます。 |
| 圧縮率 | 100倍以下 | 展開後合計サイズをZIPの圧縮後サイズで割った値です。圧縮後サイズが0の場合は比率の検証対象外です。 |
| Skillアイコン | 1MB以下、PNG・JPEG/JPG・WebP、縦横各10,000px以下 | アイコンを設定する場合だけの制限です。入力画像と変換後の画像の両方が1MB以下であることを確認します。画像なしで保存できます。 |

## よくある誤解

- **Skillを作れば、すべてのAgentで使えるわけではありません。** 利用するAgentの「プラグイン」へ追加し、利用者がアクセスできる公開範囲であることを確認します。
- **「組織」にすると、外部サービスへの操作まで全員に許可されるわけではありません。** Skillの公開範囲、Agentの共有、ツールの認証、接続先データの権限は別に確認します。
- **`SKILL.md`だけを置けば内容は自由というわけではありません。** frontmatterの`name`と`description`が必要で、スキルIDには形式・重複の制限があります。
- **フォルダを選択した場合に、サイズ制限を回避できるわけではありません。** フォルダはZIP化され、同じZIPの検証を受けます。
- **Skillにツールを選べば、必ず毎回実行されるわけではありません。** Agentの指示、依頼内容、認証・権限、実行時の状況を確認し、影響の小さい入力で結果を検証します。
- **過去バージョンを開いている状態で、その版を直接更新できるわけではありません。** 過去バージョンは読み取り専用です。

## 確認できない場合

画面の表示や保存結果がこの記事と異なる場合は、完了として扱わず、次を確認します。

1. 対象の組織・Project、Skill名、Agent名、公開範囲「組織」または「非公開」を記録します。
2. `SKILL.md`のfrontmatter、ZIP内の`SKILL.md`の位置、サイズ・ファイル数、選択した「ツール」を確認します。
3. 操作日時、実施した手順、表示されたエラー、保存後に開き直した結果を記録します。認証情報、Secret、機密ファイルの中身は共有しません。
4. 権限、提供状態、公開範囲を管理者へ確認します。仕様として保証されていない上限、契約条件、利用可否は[制限・提供条件の索引](../operations/limits-and-availability-index.md)で確認するか、担当者へ問い合わせます。
