# Pageのバージョンを管理する

Pageを更新するときは、利用者に提供される内容と、履歴に残す版を分けて確認します。この記事では、Pageの**適用中のバージョン**を確認し、新しい版を適用する方法、過去の版を「復元して適用」で切り替える方法、切り替え後に確認する項目を説明します。

バージョンの操作は、単に表示する版への参照先を変更するだけではありません。新しい版のアップロードや過去版の復元では、選んだ版のファイルが現在のPageコンテンツとして適用されます。利用者に影響する変更として、事前確認と適用後の動作確認を行ってください。

## バージョンと適用状態

Pageには複数のバージョンを保持でき、いずれか1つが「適用中」として扱われます。Pageカードには、適用中の版の名称、作成日時、またはバージョン番号が `Ver.` として表示される場合があります。「バージョン履歴」では、適用中の版に「適用中」と表示されます。

| 項目 | 確認できる内容 | 操作時の扱い |
|---|---|---|
| 適用中のバージョン | 現在のPageコンテンツとして使われる版 | 「復元して適用」の対象にはできません |
| バージョン履歴 | 版の名前、作成日時、説明、アップロードした人 | 過去の版を選び、適用先にできます |
| 新しいバージョン | 新しいZIPパッケージから作る版 | アップロード後、現在のPageコンテンツを置き換えます |
| バージョン情報 | 版ごとの「名前」「説明」 | 内容を更新できます。名前や説明だけを変えても、適用中の版は切り替わりません |

> **より大きい番号のバージョンと「適用中」のバージョンは、常に同じとは限りません。** 過去の版を復元して適用した後も、より大きい番号の版が履歴に残ることがあります。利用者に提供したい内容は、番号だけで判断せず「適用中」の表示と実際のPageで確認してください。

## 始める前に

- 対象の組織、Project、Pageが正しいことを確認します。
- Pageを更新できる権限があることを確認します。権限や機能の設定によっては、メニューや操作が表示されない、または選択できない場合があります。
- 現在「適用中」の版、変更の目的、切り替え候補の版を記録します。利用中のPageでは、切り替え時刻と確認担当者も決めます。
- 新しい版を適用する場合は、アップロードするZIPと、Pageで確認する代表的な画面・入力・業務操作を準備します。ソースの準備方法は[Pageのビルド・起動・更新](../development/page-build-start-update.md)を参照してください。
- 外部送信、登録・更新・削除を行うPageでは、検証時の影響範囲を関係者と確認します。

> バージョンの切り替えは、アクセス設定を変更する操作ではありません。誰がPageを開けるか、外部向けURLを案内できる状態かは、登録・公開およびアクセス設定とあわせて確認してください。詳しくは[画面からPageを登録・公開する](register-and-publish-pages.md)を参照してください。

## 1. 現在適用されている版を確認する

1. 対象のPageがある一覧またはカードを開きます。
2. Page名とProjectが対象と一致することを確認します。
3. Pageカードに `Ver.` が表示されている場合は、表示内容を控えます。名前が設定された版では名前、名前がない版では作成日またはバージョン番号が表示される場合があります。
4. Pageのメニューから「バージョン履歴」を選択します。
5. 履歴内で「適用中」と表示された版を確認します。
6. 版の名前、説明、作成日時、アップロードした人を確認し、今回の切り替え対象と取り違えていないか確認します。

履歴に独自の名前がない版は、日時を見出しとして表示されます。変更内容を識別しやすくするため、テスト済み・承認済みなどの意味が分かる名前と説明を付け、変更目的や確認結果は別途記録しておくことをおすすめします。

## 2. 新しいバージョンをアップロードして適用する

新しいZIPから版を作り、その内容を現在のPageへ適用する手順です。

1. 対象Pageのメニューから「新しいバージョンをアップロード」を選択します。
2. 作成したZIPファイルを1つ選択します。
3. 選択したファイル名とサイズを確認します。
4. 「アップロード」を選択します。
5. 完了メッセージが表示されたら、一覧を更新し、Pageカードの `Ver.` と「バージョン履歴」の「適用中」を確認します。
6. 「プレビュー」または実際の利用入口でPageを開き、準備した画面・操作・結果を確認します。

アップロード中はダイアログを閉じたり、同じ更新を繰り返したりせず、完了またはエラー表示を待ちます。ZIP以外のファイル、複数ファイルの同時選択、画面に表示された上限を超えるファイルは受け付けられません。

> **アップロード完了の表示だけで、業務上の利用確認を省略しないでください。** 新しい版を適用した後にPageの再ビルドが起動するため、画面が開くことだけでなく、代表的な操作と結果を確認してから利用者へ案内します。ビルド・起動の詳細は[Pageのビルド・起動・更新](../development/page-build-start-update.md)で扱います。

## 3. 過去のバージョンを復元して適用する

直前の変更を取り消したい、または既知の状態に戻したい場合は、履歴から対象の版を選びます。

1. 対象Pageのメニューから「バージョン履歴」を選択します。
2. 「適用中」ではない版について、名前、説明、日時、アップロードした人を確認します。
3. 対象の版のメニューを開き、「復元して適用」を選択します。
4. 「切り替えました」と表示されることを確認します。
5. 履歴を開き直し、選んだ版に「適用中」と表示されることを確認します。
6. Pageを開き、戻したかった表示・操作・業務結果が復元されているか確認します。

「復元して適用」は、過去版のファイルを現在のPageコンテンツとして適用し、適用中の版を切り替える操作です。**復元のために新しいバージョン番号を作る操作ではありません。** また、過去版を適用しても、後からアップロードした版が履歴から自動で削除されるわけではありません。

> 切り替えの途中でエラーが表示された場合や、完了の表示を確認できない場合は、同じ操作を直ちに繰り返さないでください。履歴の「適用中」表示と実際のPageを確認し、処理中の可能性がある場合は時間をおいてから再確認してください。

## 4. 名前・説明の更新と版の削除を扱う

履歴の各版では、メニューから「バージョン情報を編集」を選び、「名前」と「説明」を更新できます。版を識別するための情報であり、編集してもPageコンテンツは切り替わりません。

不要な版は「削除」から削除できます。ただし、削除するとその版は復元できません。「適用中」の版を削除しようとすると、別の版がある場合はそちらへ切り替わることがあります。版が1つしかない場合は削除できません。削除後に「適用中」の表示とPageの動作を確認してください。

| 操作 | Pageコンテンツへの影響 | 実施前の確認 |
|---|---|---|
| 「バージョン情報を編集」 | 適用中の内容は変わりません | 名前・説明が対象の版に対応している |
| 「復元して適用」 | 選択した過去版の内容に切り替わります | 利用者・業務・外部連携への影響を確認した |
| 「削除」 | 適用中以外の版を履歴から削除します | 今後復元する必要がないことを確認した |

## 5. 切り替え後に確認する

1. Pageカードの `Ver.` と「バージョン履歴」の「適用中」が、意図した版を示すことを確認します。
2. 利用者と同じ入口・権限でPageを開き、画面が表示されることを確認します。
3. 変更に関係する代表的な閲覧、入力、検索、実行などを試し、結果を確認します。
4. 外部サービスへの送信やデータの登録・更新・削除がある場合は、検証データまたは許可された方法で結果を確認します。
5. 切り替えた版、日時、変更理由、確認結果、未確認項目を関係者に共有します。

> Pageの画面が表示されない、想定外の内容が出る、または業務操作の結果を確認できない場合は、原因が分かるまで新たな更新や復元を重ねないでください。現在「適用中」の版、直前に行った操作、表示されたメッセージ、再現手順を記録して管理担当者へ連絡してください。
