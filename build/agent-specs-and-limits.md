# Agentの仕様・制限

Agentは、指示・モデル・参照情報・利用可能な機能を組み合わせて、会話で実行する設定単位です。本記事ではAgent固有の設定条件と、確認できた上限のみを一覧化します。設定手順は[Agentを作成して指示・モデルを設定する](create-agent-instructions-and-models.md)、ツール・Skill・Datasetの設定は[Agentにツール・Skill・Datasetを設定する](configure-agent-tools-skills-datasets.md)を参照してください。契約・プラン・機能横断の提供条件は、[制限・提供条件の索引](../operations/limits-and-availability-index.md)で確認します。

## この記事の範囲

ここで扱うのは、Agentの作成・設定・Agentとのチャットに直接関係する仕様です。Dataset自体の取り込み条件、Storageの容量、契約上の利用人数やクレジットは扱いません。また、画面に表示される候補や作成可能数が組織設定・権限・プランによって変わる場合、全組織共通の数値としては記載しません。

## 基本設定の仕様

| 項目 | 仕様 | 補足 |
|---|---|---|
| Agent名 | 名前は必須です。 | 一覧で識別するための表示名です。文字数上限は「上限・制限値」を参照してください。 |
| 説明・タグ・アイコン | 説明、タグ、アイコンを設定できます。 | 説明は利用者への用途案内、タグは分類に用います。Agent名とは役割を分けて記載します。 |
| 指示 | 「指示 (システムプロンプト)」で、役割・判断基準・出力形式・禁止事項を設定できます。 | 指示の文字数上限は、現時点で確認できていません。長い指示が必要な場合も、画面の入力エラーと実際の応答を確認してください。 |
| 有効状態 | 「有効」のAgentを利用・プレビューできます。 | 必須項目が未入力の間は有効化できません。設定変更を反映して確認するには保存が必要です。 |
| 質問例 | 「質問例」を登録できます。 | 会話での利用例を示すための設定であり、指示そのものを置き換えるものではありません。 |
| ユーザーごとの設定 | 「ユーザーごとのカスタマイズを許可」を有効にすると、利用者ごとのカスタム指示をシステムプロンプトに追加できます。 | Agent共通の指示と、各利用者のカスタム指示は別の設定です。 |

## モデルと応答の仕様

| 項目 | 仕様 | 補足 |
|---|---|---|
| 使用可能なモデル | 「使用可能なモデル」で候補を限定するか、「すべてのモデルを許可する」を選べます。 | 表示・選択できるモデルは、組織で利用可能なモデルと設定に依存します。モデル名を指示に書いても、利用可能にはなりません。 |
| デフォルトモデル | 追加した候補から「デフォルトに設定」できます。 | デフォルトに設定中のモデルは削除できません。別の候補をデフォルトにしてから外します。 |
| モデル機能の対応 | モデルによってはファイルアップロード、プラグイン、画像・動画アップロードをサポートしません。 | Agent側で許可していても、選択したモデルが対応しない機能は利用できません。 |
| 最大出力トークン数 | 「最大出力トークン数」で、1回の応答の出力量を設定できます。 | 設定可能な範囲は「上限・制限値」を参照してください。実際に出力できる量は選択モデルや入力内容の影響も受けます。 |
| 既定のエフォート | 「既定のエフォート」で推論の深さを設定できます。 | チャットで利用者がエフォートを選んだ場合はそちらが優先されます。未指定時はモデルごとの標準設定が使われます。 |
| 過去の会話参照 | 「過去の会話参照」で、応答時に参照する過去のメッセージ数を設定できます。 | 多くすると長い文脈を保持しやすくなりますが、消費クレジットが増加します。 |

## ツール・Skill・Dataset・共有の仕様

| 項目 | 仕様 | 補足 |
|---|---|---|
| プラグイン | 「プラグイン」でAgentが使うツールやSkillを追加できます。 | 追加できる候補は組織の提供状態、権限、接続・認証の状態に依存します。1つのAgentに追加できる件数の共通上限は確認できませんでした。 |
| Skillの公開範囲 | 組織に公開するAgentへ非公開Skillを含めると、他の利用者はそのSkillを利用できません。 | 画面の「公開範囲の変更が必要です」に従い、Agentの対象利用者とSkillの公開範囲を整合させます。 |
| データ連携 | 「データ連携」でDatasetを選択し、回答時の参照情報として利用できます。 | Datasetを選んでも、資料の取り込み完了や利用者の参照権限は自動では補われません。非公開Datasetを含むAgentを共有するときは、対象者が参照できるかを確認します。 |
| Agentのアクセス権限 | 利用・管理の権限を、組織、部署、メンバーの単位で設定できます。 | Project内で作成するAgentは、Projectの全メンバーが利用できる権限を前提に扱われます。個別の編集・利用可否は、ProjectとAgentの権限を両方確認してください。 |
| 作成可否・作成数 | Agentの作成機能および作成数は、組織のプラン・設定によって制御されます。 | プランごとの数値は本記事では扱いません。画面の案内と[制限・提供条件の索引](../operations/limits-and-availability-index.md)を確認してください。 |
| 組織Agentの共有 | 組織内で利用するAgentの共有・設定変更には、組織のIAM設定と権限が適用される場合があります。 | 画面に操作が表示されない、または保存できない場合は、共有対象だけでなくAgent設定を変更する権限も確認します。 |

## Agentとのチャット・ファイル添付の仕様

| 項目 | 仕様 | 補足 |
|---|---|---|
| 添付できるファイル形式 | 「アップロード可能なファイルタイプ」で許可する分類を限定できます。未指定の場合は既定の対応形式が適用されます。 | 対応形式でも、選択モデルがファイルアップロードに対応しない場合は利用できません。 |
| 添付ファイル数 | 「最大ファイルアップロード数」で、1回のメッセージに添付できる数を設定します。 | Agentの設定値が優先され、未設定時は既定値が用いられます。設定可能な範囲と既定値は次節を参照してください。 |
| 添付ファイルのサイズ | チャット添付では、PDFとそれ以外のファイルで事前チェックの上限が異なります。 | サイズが上限内でも、ファイル形式、Agent設定、選択モデルなどの条件を満たす必要があります。 |
| ファイルの扱い | 「ファイルをテキストとして扱う」を有効にすると、対応ファイルをテキストとして展開できます。 | 無効時はファイルがワークスペースに保存されます。PDFをLLMへ直接送信する設定は、対応モデルでのみ意味を持ちます。 |
| プラグイン呼び出し | 「プラグイン呼び出しの最大回数」で、1回の回答における呼び出し回数を設定できます。 | 一部のプラグインは呼び出しが表示されない場合があります。 |

## 上限・制限値

次表は、コードで値と適用条件を確認できたものだけです。プラン・組織設定に依存する作成数や利用可否の数値は、ここには記載しません。

| 項目 | 上限・制限値 | 条件・補足 |
|---|---|---|
| Agent名 | 255文字 | 作成・更新時の「エージェント名」。1文字以上が必要です。 |
| 最大出力トークン数 | 1,000〜1,000,000 | 「最大出力トークン数」を明示して設定する場合の入力範囲です。未設定時の出力上限は、モデル側の条件に依存するため固定値ではありません。 |
| 過去の会話参照 | 0〜500往復、既定50往復 | 画面では会話の往復数として設定します。内部では個別メッセージ0〜1,000件、既定100件として保存されます。 |
| Temperature | 0〜2 | 「Temperature」を明示して設定する場合の入力範囲です。 |
| プラグイン呼び出しの最大回数 | 1〜200回、既定20回 | 1回の回答に対する設定範囲・既定値です。 |
| 最大ファイルアップロード数 | 1〜20ファイル | 「最大ファイルアップロード数」に設定できる範囲です。設定画面の既定値は5です。ただし、Agentに値が保存されていない場合、通常チャットの添付処理は10ファイルを使用します。実際のAgent設定を確認してください。 |
| 添付PDFのサイズ | 200 MiB以下 | Agentとの通常チャットでPDFを添付する場合の事前チェックです。200 MiBを超えるPDFは添付できません。 |
| 添付ファイルのサイズ | 512 MiB以下 | Agentとの通常チャットで添付する各ファイルのサーバー側チェックです。PDFは上記200 MiBの条件も満たす必要があります。 |

## よくある誤解

- **「使用可能なモデル」に追加すれば、すべての利用者が必ず同じモデルを使える**とは限りません。組織での提供状態・使用禁止設定・モデルの対応機能を確認します。
- **Agentを共有すれば、非公開Skillや非公開Datasetも利用者に自動共有される**わけではありません。利用者が各リソースへアクセスできるかを確認します。
- **添付数を20に設定すれば、20個の任意のファイルを必ず送れる**わけではありません。形式、各ファイルのサイズ、モデル対応も満たす必要があります。
- **「最大出力トークン数」を大きくすれば、常に長い回答になる**わけではありません。モデルの制約、入力内容、会話の文脈、応答の途中終了などの影響を受けます。
- **Agentを「有効」にすることと、利用対象者に権限を付与することは同じではありません。** 有効状態、Agentのアクセス権限、Skill・Dataset・接続先の権限を分けて確認します。

## 確認できない場合

画面に候補が出ない、保存・有効化できない、または想定利用者が使えない場合は、次を順に確認してください。

1. 「使用可能なモデル」、Agentの「有効」、アクセス権限、対象Projectを確認します。
2. 「プラグイン」「データ連携」の選択内容と、Skill・Datasetの公開範囲、取り込み状態、接続・認証状態を確認します。
3. 添付時は「アップロード可能なファイルタイプ」、添付数、ファイル形式・サイズ、選択モデルの対応状況を確認します。
4. 作成機能や作成数に関する案内が出る場合は、組織の管理者または契約・プランの確認担当者へ、表示されたメッセージ、対象組織・Project、Agent名、操作日時を添えて問い合わせます。
5. 数値の根拠が必要な場合は、本記事の「上限・制限値」にない値を推測せず、プロダクト担当またはサポート窓口へ確認します。
