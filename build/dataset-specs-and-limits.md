# Datasetの仕様・制限

Datasetは、業務資料や外部データを取り込み、AgentやWorkflowから**RAG検索**で参照するための情報源です。取り込める形式、更新方法、参照時の性質を先に確認すると、資料更新後に古い情報が使われる、期待した資料が回答に現れない、といった問題を防げます。

- データを準備して取り込む手順：[Datasetを準備して参照させる](prepare-and-reference-datasets.md)
- 制限・提供条件を横断して確認する：[制限・提供条件の索引](../operations/limits-and-availability-index.md)
- Agentが資料を参照しない場合：[Agentがデータを参照しない](../troubleshooting/agent-not-using-data.md)

## この記事の範囲

この記事では、Datasetへデータを**取り込む条件**、外部データを**同期・再読み込みする条件**、AgentやWorkflowから**参照する際の性質**を説明します。Datasetの作成・共有・アップロードの操作手順は[Datasetを準備して参照させる](prepare-and-reference-datasets.md)、Agentへの設定は[Agentにツール・Skill・Datasetを設定する](configure-agent-tools-skills-datasets.md)を参照してください。

契約プラン、組織の設定、権限、接続済みの外部サービスによって、表示される取り込み元、操作できる項目、利用できる機能は異なります。本記事にない上限値や契約ごとの容量は、画面表示と管理者・JAPAN AI CSチームへの確認を優先してください。

## 取り込み・同期・参照の仕様

| 項目 | 仕様 | 補足 |
|---|---|---|
| 取り込み元 | 「データアップロード」では「ファイル」「URL」「外部API」を選べます。 | 外部APIは、組織設定で対象のデータ連携を設定・認証済みの場合に利用します。 |
| ファイル形式 | 画面で選択できる通常ファイルは、TXT、CSV、DOCX、PPTX、PDF、XLSX、MBOX、HTML、HTM、Markdown（.md）、MP3、MP4、WAV、WEBM、PNG、JPG、JPEG、WebP、HEIC、HEIFです。 | 画面に表示・選択できる形式と、実際に処理できる内容は異なり得ます。暗号化・破損・内容が読み取れないファイルは「読み取り不能」になる場合があります。 |
| URL | URLを指定してWebの内容を取り込めます。 | URLはHTTPまたはHTTPSの有効なURLである必要があります。アクセス制限、取得先の状態、ページ内容により取り込めない場合があります。 |
| 外部データ | 取り込み元として扱われるものには、Google Drive、Confluence、Dropbox、Box、Salesforce、OneDrive、SharePoint、Slack、Chatwork、Zendesk、kintone、Notion、GENIEE SFAがあります。 | 利用可否は、組織での提供状態、接続設定、接続アカウントの権限に依存します。接続済みでも、対象データの閲覧権限がなければ取得できません。 |
| PDFの抽出方法 | PDFでは「テキスト検出」「OCR」を選べ、提供状態によって「AI OCR」を選べる場合があります。 | 「AI OCR for PDF」を有効にすると、PDF内の画像をAIモデルが検出・処理します。無効化後も、すでに取り込み済みのデータは自動再処理されません。 |
| 更新頻度 | 「更新頻度」で自動更新の頻度を選択できます。 | **PCからアップロードしたファイルは自動更新の対象外**です。ファイルを更新した場合は、更新版を取り込んでください。 |
| データセット再読み込み | 「データセット再読み込み」は、取得元（Web／外部API）から最新データを再取得して再インデックスします。 | 更新中は再読み込みできません。再読み込み後も、データ一覧の「ステータス」と代表質問で結果を確認してください。 |
| 処理状態 | データ一覧では「保留中」「進行中」「完了」「更新」「削除中」「失敗」「コンテンツなし」「読み取り不能」などが表示されます。 | AgentやWorkflowで参照する前に、対象データが「完了」であることを確認します。処理中・失敗・コンテンツなし・読み取り不能のデータは、期待どおりに参照できない可能性があります。 |
| 共有と参照 | Datasetは非公開、組織全体、または指定した部署に共有できます。Project内では、作成者のみまたはプロジェクトメンバー全員を対象にする表示があります。 | 非公開のDatasetを接続したAgentを共有すると、他の利用者も内容を閲覧できる可能性があります。資料の共有範囲と、Agent経由で回答に利用してよい範囲を分けて確認してください。 |
| ProjectへリンクしたDataset | 組織またはグローバルのDatasetをProjectへリンクして利用できます。 | リンクしたDatasetはProject内では読み取り専用です。名称、更新頻度、再読み込み、削除、データ内容の変更が必要な場合は、作成元で対応するか、Projectからのリンク解除を検討します。 |
| RAG検索 | AgentやWorkflowは、設定したDatasetに対してRAG検索を行えます。 | Datasetを設定しても、毎回すべての資料が回答に使用されるわけではありません。質問に関連すると判断された部分を検索して利用します。 |

## 上限・制限値

以下は、確認できた値だけを掲載しています。画面に件数・容量・クレジット上限が表示される場合は、その組織に適用される表示を優先してください。

| 項目 | 上限・制限値 | 条件・補足 |
|---|---:|---|
| ファイルのサイズ | 1ファイルあたり200MBまで | Datasetへのファイルアップロード時の上限です。200MB以上のファイルはアップロードできません。 |
| URL指定取り込み | 1回のリクエストにつき1〜100件 | Dataset APIでURLを取り込む場合です。各URLはHTTPまたはHTTPSの有効なURLである必要があります。Web画面でのクロール範囲・階層数・ページ総数の固定上限は、確認したコードからは示せません。 |
| 自動更新の選択肢 | なし、3時間ごと、6時間ごと、12時間ごと、24時間ごと、72時間ごと、7日ごと、15日ごと、30日ごと | Webまたは外部APIを取得元にした更新の設定です。PCからアップロードしたファイルは自動更新の対象外です。実行時刻・取得完了時刻を保証する値ではありません。 |
| AI OCRのクレジット | PDFの1ページごとに消費 | 「AI OCR for PDF」または「AI OCR」を利用する場合です。利用できるか、残高・上限により実行できるかは、組織・プラン・クレジット設定に依存します。 |

## よくある誤解

### Datasetへ入れれば、更新版が自動で反映される

自動更新の対象はWebまたは外部APIを取得元とするデータです。PCからアップロードしたファイルは対象外です。資料を差し替えたときは、更新版を取り込み、古い版を残すか削除するかを決めてください。外部データは、更新頻度または「データセット再読み込み」の実行後に、処理状態と参照結果を確認します。

### 「完了」と表示されたら、どの質問にも正しく答えられる

「完了」は取り込み処理が終わったことの確認です。質問に対する回答の正しさ、最新性、必要な根拠が選ばれることまでは保証しません。資料の現行性、Agentで選択したDataset、質問の表現、回答のデータ参照先を確認してください。

### Datasetは長文を常に全文読んで、すべてを点検する

DatasetのRAGは、質問に**関連する部分を検索して参照する仕組み**です。長文の全件網羅や全文チェックには向きません。たとえば、契約書の全条項を漏れなく確認する、規程の全改定点を列挙するといった業務では、対象ファイルと確認範囲を明示し、取得できた内容を別手順で照合してください。これは製品を安全に活用するための案内です。

### 共有したAgentなら、誰でも同じようにDatasetを使える

Agentの共有とDatasetの共有・閲覧可否は別に確認が必要です。利用者、部署、Project、接続先の認証、権限によって、表示・編集・参照できる範囲が変わります。機密資料では、最小限の共有範囲でテストしてください。

## 確認できない場合

次の順に切り分けます。

1. 対象の「データセット」、データ名、取得元、更新日時、共有範囲が正しいか確認します。
2. データ一覧で「ステータス」を確認します。「失敗」「コンテンツなし」「読み取り不能」の場合は、元ファイル・URL・外部サービス側の権限・接続状態を見直します。
3. Webまたは外部APIの更新では、「更新頻度」と最終更新状況を確認し、必要なら「データセット再読み込み」を実行します。更新中は完了を待ちます。
4. Agentでは「データ連携」に必要なDatasetだけが設定されているか、回答のデータ参照先と元資料が一致するかを確認します。
5. 上限到達、アップロード不可、外部APIが選べない、クレジットに関する表示がある場合は、組織管理者へ画面表示・操作日時・対象Datasetを添えて連絡します。機密資料の本文や認証情報は連絡に含めません。

参照されない問題の切り分けは[Agentがデータを参照しない](../troubleshooting/agent-not-using-data.md)を参照してください。
