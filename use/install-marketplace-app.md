# MarketplaceからAppをインストールする

この記事では、選定済みのStudio AppをMarketplaceから組織へインストールし、導入結果を確認する手順を説明します。対象は、Appの導入を担当する方です。

**インストールは、単に自分の画面へショートカットを追加する操作ではありません。** 組織でAppを利用できるようにする操作であり、料金への同意が必要な場合もあります。対象の組織と承認内容を確認してから進めてください。

Appの比較・選定は[MarketplaceでAppを選ぶ](choose-marketplace-app.md)、導入後の接続・利用者などの準備は[Appの初期設定を完了する](complete-app-setup.md)で扱います。自分で作成したAppを組織内へ導入する手順や、JAI Adminでの配布操作はこの記事の対象外です。

## 始める前に

- 導入するAppと、導入先の組織が決まっている。
- 用途・必要な権限・外部接続・費用を確認し、必要な組織内承認を得ている。
- 操作するアカウントに、その組織へのApp導入に必要な権限がある。
- 導入後の初期設定と利用者の管理を担当する人が決まっている。
- 同じAppがすでに導入済み、または他の担当者が導入中ではないか確認できる。

> 以下はPCのWebブラウザでの標準画面を中心に説明します。入口、ボタン、料金表示、選べる操作は、組織の設定・権限・Appの提供状態によって異なります。全員が同じ操作を行えるわけではありません。

## 1. 対象組織とAppの状態を確認する

1. 現在選択している組織を確認します。
2. 「Studio Apps」などのAppの入口から「マーケットプレイス」を開きます。
3. 選定済みAppを探し、「詳細を見る」などの操作で詳細画面を開きます。
4. App名と提供元を確認します。
5. 導入状態と、表示されている操作を確認します。

| 表示・状態の例 | 次に行うこと |
|---|---|
| インストール | 詳細を再確認し、確認画面へ進む |
| JAPAN AIに問い合わせる | 問い合わせ先へ導入を依頼する。この手順で直接確定できるAppとは区別する |
| インストール中 | 追加で実行せず、現在の処理結果を確認する |
| インストール済み／開く | 新規導入ではなく、既存Appの利用・初期設定へ進む |
| 参加／管理者に依頼 | Appは導入済みでも、自分の参加やアクセスの確認が必要。再インストールで解決しようとしない |
| インストール失敗／再試行 | 最新状態とエラーを確認してから、後述の再試行手順を判断する |
| 現在利用できない／導入権限に関する案内 | 管理者やサポートへ確認する |

**一覧を閲覧できることと、インストールを確定できることは別です。** ボタンが出ない場合は、権限だけでなく、問い合わせが必要なAppか、購入・提供条件に制限がないかも確認してください。

すでに導入済みなら、[導入済みAppを開いて利用を始める](open-installed-app.md)を参照します。

## 2. インストールの確認画面を開く

詳細画面の「インストール」を選びます。確認画面を開いただけでは、インストールは確定していません。

確認画面で、次の内容を見直します。

| 確認項目 | 確認する内容 |
|---|---|
| App名 | 選定・承認されたAppと一致しているか |
| 導入先 | 現在選択している組織でよいか。不明なら確定前に戻って確認する |
| 導入後の利用先 | 導入後に対象Appをこの組織で利用することを理解したか |
| 接続設定 | インストール後に外部サービスの接続設定が必要という案内があるか |
| 同意内容 | 組織への導入と、料金がある場合はその課金条件に同意してよいか |

詳細画面で確認した必要権限・外部接続と、組織内で承認された内容に差がある場合は、確定せずに担当者へ確認します。

この操作は、既存Projectを選んでAppの部品を追加する手順ではありません。また、インストールしただけで外部サービスへの接続や、すべての利用者の準備が完了するとは限りません。

### 料金が表示される場合

確認画面に料金が表示されたら、少なくとも次の点を確認します。

- 対象の人数・シート数など、料金計算の単位
- 今回の課金額
- 次回の更新日と月額
- 導入する本人の利用枠に関する説明
- 毎月の課金を含む同意内容

標準画面では「シート」「クレジット」という単位で表示される場合があります。導入者が管理者として1シートを利用する旨の案内が出た場合は、導入者も利用枠に含まれる点を確認してください。実際の条件は、その確認画面と契約内容に従います。

**今回の支払いだけでなく、継続時の料金も確認してください。** 利用予定人数が複数の場合、確認画面の対象数だけですべての利用者を利用可能にできるとは判断しません。利用者追加とその料金影響は、初期設定・人数管理の手順で確認します。

Appの料金と、AI処理などの実行消費・外部サービス側の費用は分けて確認します。「無料」という表示だけで、業務全体の費用がゼロとは判断しないでください。

料金・人数・更新条件が承認内容と異なる場合は、確定前に「キャンセル」で戻り、担当者へ確認します。

## 3. 内容に同意してインストールを確定する

1. 導入先、App名、接続の前提、料金と更新条件を最終確認します。
2. 確認画面の同意欄にチェックを入れます。
3. 「インストール」または「確認してインストール」を選びます。
4. 処理中の表示を確認し、応答を待ちます。

同意していない状態や処理中は、確定操作ができない場合があります。反応がないように見えても、同じ操作を連打したり、別のタブから同時に実行したりしないでください。

確定前の「キャンセル」と、確定後の処理の取り消しは別です。**確定後に画面を閉じても、インストールや課金が取り消されたとは判断しません。** 誤った組織で確定したなどの場合は、現在の導入状態を確認し、管理者やサポートへ連絡してください。自分で削除・再導入を繰り返して解決しようとしないでください。

### 確認中に情報が変わった場合

「シートの料金が変更されました」（以前の表示では「シートの見積もりが変更されました」）「確認中にアプリが更新されました」などと表示される場合があります。

1. 「再読み込み」などの案内に従って最新情報を取得します。
2. Appの内容・必要条件・今回の料金・更新条件を読み直します。
3. 承認済みの範囲内か確認します。
4. 問題がなければ、改めて同意して確定します。

以前の内容への同意を、変更後の内容にもそのまま適用しないでください。最新情報を取得できない場合は、そのまま確定を繰り返さず、状態を確認します。

## 4. インストール結果を確認する

確定後は、通知だけでなく、対象Appの詳細画面や一覧の最新状態を確認します。

### インストールが完了した場合

「アプリをインストールしました」という通知や、対象Appが導入済みになったことを確認します。「開く」などの操作が表示される場合は、対象Appへ進めるか確認します。

表示が古いままの場合は、対象の組織とAppを確認したうえで、詳細画面を開き直すなどして最新状態を取得してください。

他の担当者が導入したAppなどでは、導入済みでも自分にはアクセス権がない場合があります。「参加」が表示された場合は、App Projectへ参加してから開く場合があります。「管理者に依頼」などの案内に従う場合と区別し、新規インストールとは分けて対応します。

### インストール中の場合

「インストール中」は完了ではありません。画面を離れて後で戻れるという案内がある場合は、同じ組織・Appの詳細画面へ戻って状態を確認します。

標準画面では、インストール中の状態を2秒間隔で、開始後最大約2分間確認します。ただし、特定の時間内に必ず完了することを前提にしないでください。表示が変わらないときや確認の終了後は、画面を開き直して最新状態を確認します。

### 結果が分からない場合

通信が途切れた、画面を閉じた、または「インストールが完了したか確認できませんでした」と表示された場合は、次の順で確認します。

1. 対象組織のMarketplaceで、同じAppの詳細を開き直します。
2. 導入済みなら、再度インストールせず、初期設定へ進みます。
3. インストール中なら、結果確認を続けます。
4. 失敗や利用不可が表示された場合は、その案内に沿って対応します。
5. 状態が確認できない場合は、管理者やサポートへ問い合わせます。

**応答が返らなかったことだけで、導入されていない、または課金されていないとは判断しません。** 再実行の前に、現在の状態を確認してください。

## 5. 初期設定へ引き継ぐ

導入後に「セットアップを完了」や、残りの設定件数が表示された場合は、初期設定が必要です。設定担当者と、残っている作業を確認します。

- 対象の組織とApp
- インストール結果を確認した日時
- Appを開ける担当者
- 画面に表示された未設定項目やエラー
- 外部接続・秘密情報・利用者追加など、次に確認する作業

セットアップ状況を読み込めない場合は、「設定が不要」「設定済み」と判断しません。画面を更新して再確認します。

**インストール完了、画面上のセットアップ完了、業務での利用準備完了は区別してください。** セットアップ欄だけで、個人ごとの接続・必要な利用者の参加・業務データを使った動作確認まで完了したとは判断しません。

続きは[Appの初期設定を完了する](complete-app-setup.md)で扱います。必要な準備が終わるまでは、他の利用者へ「すぐ業務利用できる」と案内しないでください。

## うまくいかないとき

| 状況 | 対応 |
|---|---|
| インストールを選べない | 組織、導入権限、問い合わせ型かどうか、購入・提供条件を確認する |
| クレジット不足 | 管理者へ確認し、必要な対応後に購入内容を見直す |
| シートを購入できない旨が表示される | 管理者またはJAPAN AIへ問い合わせる。権限変更や別アカウントでの回避を試さない |
| 料金（以前は見積もりと表示）やApp情報が変更された | 最新情報を再取得し、承認範囲を確認して改めて同意する |
| バージョンを利用できない | 最新のApp情報と導入状態を確認する。利用不可が続く場合は問い合わせる |
| インストール失敗 | 最新状態とエラーを確認する。「再試行」が案内される場合は、内容を確認して実行する |
| 再試行しても失敗する／サポートが必要 | 再実行を繰り返さず、管理者やサポートへ連絡する |
| 完了したか分からない | 再試行の前に、同じAppの最新の導入状態を確認する |
| 導入済みなのに開けない | Appへの参加・アクセス権を確認する。再インストールとは分けて対応する |

問い合わせには、組織名、App名、操作日時、エラーの表示、現在の導入状態、行った再確認を添えます。パスワード、APIキー、外部サービスの認証情報は添えないでください。

## 完了チェック

- [ ] 正しい組織とAppで操作した
- [ ] 導入と費用に必要な承認を確認した
- [ ] 確認画面の内容を読み、必要な同意をして確定した
- [ ] 導入済みの状態を確認し、処理中・結果不明を完了と扱っていない
- [ ] 初期設定の有無と、次の担当者・作業を確認した
- [ ] インストール完了だけで業務利用の準備完了とは案内していない
