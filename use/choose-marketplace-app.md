# MarketplaceでAppを選ぶ

Marketplace（マーケットプレイス）は、組織で利用するStudio Appを探す入口です。この記事では、候補を探し、**業務への適合・必要な権限・外部接続・費用**を確認して、導入するか判断するまでを説明します。

**一覧に表示されること、インストールできること、業務で使えることは別です。** Appを見つけても、導入権限や接続設定、利用者の追加などが必要な場合があります。

インストールの確定操作は[MarketplaceからAppをインストールする](install-marketplace-app.md)、導入後の初期設定は[Appの初期設定を完了する](complete-app-setup.md)で扱います。この記事では、確認のためにAppを導入したり、認証情報を登録したりする必要はありません。

## 始める前に

次の点を整理します。

- 導入先の組織と、解決したい業務
- 主な利用者と、利用を予定している人数
- 扱う情報と、接続を予定している外部サービス
- 導入・費用・外部接続を承認する担当者
- すでに組織へ導入されているAppで対応できないか

すでに利用先のAppが案内されている場合は、[導入済みAppを開いて利用を始める](open-installed-app.md)を参照してください。

> 以下はPCのWebブラウザでの標準画面を中心に説明します。表示されるメニュー、App、ボタン、料金情報は、組織の設定・権限・提供状態などによって異なります。画面に表示された条件と、組織の契約・運用ルールを確認してください。

## 1. Marketplaceを開き、候補を探す

1. 現在選択している組織が、導入を検討している組織か確認します。
2. 「Studio Apps」などのAppの入口を開きます。
3. 「マーケットプレイス」を選びます。
4. 検索欄へApp名や関連する語を入力し、一覧を絞ります。
5. 候補の名前・短い説明・タグ・提供元・導入状態を確認します。
6. 「詳細を見る」などの操作から、Appの詳細を開きます。

標準の検索では、App名・短い説明・タグに含まれる語で絞り込めます。長い文章で探して見つからない場合は、短い語へ変えてください。詳細説明の全文や、あらゆる同義語が検索対象になるとは限りません。

Marketplaceが表示されない場合は、別の組織を開いていないか、対象組織で利用できるかを管理者へ確認します。表示させるために自分で設定や権限を変更する必要はありません。

## 2. 自分たちの業務に合うか確認する

Appの概要や、掲載されている画像・動画・更新情報などを読みます。掲載情報の種類や詳しさはAppによって異なります。

| 確認すること | 判断のポイント |
|---|---|
| 対象業務 | 自分たちが行いたい作業と、Appが説明している用途が合っているか |
| 入力する情報 | 必要な資料やデータを用意できるか。利用を許可された情報か |
| 得られる結果 | 必要な出力や作業結果を得られるか。人が確認する範囲はどこか |
| 提供元 | 誰が提供しているAppか。導入や運用の問い合わせ先を確認できるか |
| 利用者 | 誰が使うか。導入後に利用者を追加・管理する担当者がいるか |
| 更新・運用 | 更新情報や案内を確認できるか。運用中に確認する担当者がいるか |

「公式」「認証済み」などの表示がある場合も、業務への適合性や、自組織の情報を扱ってよいかの確認は別に行います。表示だけで、出力の正確性や組織内承認まで保証されるわけではありません。

説明から分からない点は、対応していると推測せず、導入前の確認事項として残します。

## 3. 権限と接続条件を確認する

### Appが必要とする権限

詳細の「情報」「必要な権限」などを確認します。権限名が技術的で判断できない場合は、画面の記載を担当者へ伝え、どのデータに対して何ができるのか確認します。

特に、次の点が業務上の許可と合っているか見直してください。

- 情報を読むだけか、登録・変更・削除なども行うか
- 外部への送信や、外部サービスの更新を伴うか
- どの利用者・接続アカウントの権限で処理するか
- 利用者に見せてよいデータの範囲と合っているか

これらは導入判断の確認事項です。すべてが詳細画面に説明されているとは限りません。不明な点はAppの担当者へ確認します。

**「必要な権限」は、あなた自身に導入権限があることを示す表示ではありません。** Appを導入する権限、導入後のAppへアクセスする権限、外部サービスの操作権限を分けて確認してください。

### 外部サービスへの接続

「セットアップ」「インストール後に必要な認証情報」などを確認し、表示されたサービスを組織で利用できるか確認します。

| 確認すること | 導入前に決めること |
|---|---|
| 必要なサービス | 利用契約やアカウントがあるか |
| 接続するアカウント | 誰のアカウントを使い、どのデータへアクセスするか |
| 接続方式 | 個人ごとの接続か、Project・Appで共有する接続か |
| 設定担当者 | 誰が接続・承認・秘密情報の登録を行うか |
| 運用担当者 | 接続切れ、担当者変更、認証情報更新に誰が対応するか |

「追加の認証情報は必要ありません」と表示されても、利用者の追加や業務データの準備など、すべての初期設定が不要とは判断しません。

選定の相談に、パスワード・APIキー・アクセストークンを貼り付ける必要はありません。必要なサービス名と、設定できる担当者の有無を伝えます。

## 4. 料金と利用人数を確認する

料金が表示されている場合は、金額だけでなく、**単位・対象人数・今回の費用・継続時の費用**を確認します。

標準画面では「無料」や「月額シート制」、単価を「クレジット / シート / 月」で表示する場合があります。料金表示は円とは限りません。画面の単位を読み替えずに確認してください。

| 確認項目 | 見るポイント |
|---|---|
| Appの料金区分 | 無料か、人数・シートに応じた課金があるか |
| 単価と単位 | 何に対して、どの期間で、何クレジットか |
| 利用予定人数 | 管理者を含めて誰が使うか。利用者追加時の条件は何か |
| 導入時の費用 | 今回の請求・クレジット消費がいくらか |
| 継続時の費用 | 月額と次回更新日がどう表示されているか |
| 別途確認する費用 | AI実行時の消費、外部サービスの契約などを含むか |

詳細の単価表示だけで、組織全体の費用を確定しないでください。インストール確認画面に料金が示される場合は、導入を確定する前に、対象数・今回の費用・更新条件を改めて確認します。管理者本人の利用分を含む旨が表示される場合もあります。

**「無料」は、業務で使う際のすべての費用がゼロという意味には読み替えません。** Appの料金と、実行時の消費・外部サービスの料金を分けて確認します。また、料金が表示されていないことも、無料の根拠にはなりません。

人数を増減した場合や利用を終了した場合の料金・更新停止条件が不明なら、導入前に担当者へ確認してください。この記事では、人数変更・解約の操作や返金条件を一律には定めません。

## 5. 表示された導入方法を確認する

Appや現在の状態によって、次のような表示になります。

| 主な表示 | 次に行うこと |
|---|---|
| インストール | 選定・承認を済ませてから導入手順へ進む。確認画面では内容・費用を再確認する |
| JAPAN AIに問い合わせる | 自分での導入を前提にせず、用途・組織・利用予定人数・確認事項を伝える |
| 導入権限に関する案内 | 組織管理者など、権限を確認できる担当者へ依頼する |
| インストール済み／開く | 新たな導入ではなく、既存Appを利用できるか確認する |
| 参加／管理者に依頼 | 導入済みAppへの参加・アクセスを確認する。「参加」を選ぶとApp Projectへ参加してから開く場合があるため、閲覧だけのつもりで参加操作を進めない |
| インストール中 | 現在の処理状況を確認する。新たな導入操作を重ねない |
| インストール失敗／再試行 | 選定とは分けて、実行した担当者と現在の状態を確認する |
| 現在利用できない旨の案内 | 管理者やサポートへ、対象Appと表示内容を伝える |

「インストール」が表示されない理由は、権限だけとは限りません。Appが問い合わせによる導入方式である場合や、組織側の提供・購入条件による場合もあります。管理者なら必ずすべてのAppを直接導入できる、と判断しないでください。

## 6. 選定結果をまとめる

導入担当者が判断できるよう、次の項目をまとめます。未確認の項目は「未確認」として残し、承認されたものと区別してください。

> **導入を検討するApp**：App名・詳細画面のURL  
> **導入先**：組織名  
> **用途**：対象業務と期待する結果  
> **利用者**：利用予定人数・管理担当者  
> **必要な権限**：確認した内容・未確認事項  
> **外部接続**：必要なサービス・接続方式・設定担当者  
> **費用**：画面の料金区分・単価・単位・更新条件  
> **導入方法**：直接インストール／JAPAN AIへの問い合わせ／要確認  
> **承認状況**：承認者・承認済みの範囲・残る確認事項

詳細画面のURLを共有しても、閲覧・導入権限が付与されるわけではありません。共有相手が同じ組織の情報を確認できるかも確認します。

ここまでの確認ができたら、[MarketplaceからAppをインストールする](install-marketplace-app.md)へ進みます。問い合わせが必要なAppは、問い合わせ先の案内に従ってください。

## うまくいかないとき

| 状況 | 最初に確認すること |
|---|---|
| Marketplaceが見当たらない | 選択中の組織、組織での提供状態、利用できる入口 |
| 一致するAppがない | 検索語を短くする、別の語にする、検索語を消す |
| 公開中のAppがないと表示される | 現在の一覧に候補がない状態。読み込みエラーと区別する |
| 読み込みに失敗する | 画面の案内に従って再確認する。失敗を「Appが存在しない」と扱わない |
| 権限や接続の意味が分からない | 表示内容と用途を担当者へ伝える。許可範囲を推測しない |
| 料金が分からない | 無料と判断せず、Appの担当者やサポートへ確認する |
| インストールを選べない | 導入方式、権限、購入・提供条件、現在の導入状態 |

問い合わせ時は、組織名、App名、確認した日時、表示内容、行いたい業務を伝えます。機密データや認証情報を不要に添えないでください。

## 完了チェック

- [ ] 導入先の組織と用途を確認した
- [ ] 既存Appの利用で対応できないか確認した
- [ ] Appの用途・必要な権限・接続条件を確認した
- [ ] 利用予定人数・料金の単位・導入時と継続時の費用を確認した
- [ ] 導入方式と担当者、必要な承認を確認した
- [ ] 未確認事項を残したまま導入の同意・確定をしていない
