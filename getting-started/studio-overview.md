# Studioとは

JAPAN AI Studioは、AIによる処理、業務データ、操作画面を組み合わせて、業務に合ったアプリケーションを作り、チームで利用するための機能です。

資料をもとに質問へ回答する、登録されたデータを整理する、決まった手順で処理を進めるなど、日常の業務にAIを組み込めます。自分で作成するだけでなく、共有されたProjectや、導入済みのAppを利用することもできます。

この記事では、Studioの全体像と、どのような業務に活用できるかを説明します。

## Studioでできること

Studioでは、目的に応じて必要な機能を組み合わせます。最初からすべての機能を使う必要はありません。

| やりたいこと | Studioでの取り組み方 |
|---|---|
| 資料を参照しながら質問に答えてほしい | 参照する資料を用意し、Agentが必要な情報を検索して回答する構成を作ります。 |
| 案件やタスクなどの情報を整理したい | Objectに項目とレコードを用意し、データを検索・登録・更新できるようにします。 |
| 複数の処理を決まった順番で進めたい | Workflowで処理の手順を組み立て、入力から結果の出力までをつなぎます。 |
| 業務担当者が使いやすい画面を用意したい | Pageで入力フォームや一覧画面などのWebアプリケーションを作り、業務処理につなげます。 |
| ファイルを業務の中で扱いたい | Storageにファイルを保存し、必要な処理や画面から利用する構成を作ります。 |

外部サービスと連携する場合は、対応する接続方法や必要な認証情報を設定します。利用できる連携先や操作は、提供機能・権限・接続設定によって異なります。

## 例えば、タスク管理に使う場合

チームのタスク管理では、次のような構成が考えられます。

1. **Object**に、タスク名・担当者・期限・状態を保存します。
2. **Page**に、タスクの一覧や登録・更新の画面を用意します。
3. **Agent**が、登録された情報をもとに、対応状況の整理や報告文の作成を支援します。
4. 必要に応じて、**Workflow**で集計や報告の処理を組み立てます。

これは構成例です。すべてが最初から設定されているわけではなく、業務に合わせた作成・接続・権限設定が必要です。

まずは「タスク情報を整理する」など、ひとつの目的から始め、必要になった機能を追加していくことができます。

## 作る場所と、使い始める入口

Studioには、作成と利用のための入口があります。

- **Studio Workspace**：Project単位でAgent・Workflow・Pageなどを作成・管理するための領域です。
- **Project**：業務に必要なデータや機能をまとめ、メンバーと利用する単位です。作成を担当しない人も、参加しているProjectの機能を権限の範囲で利用できます。
- **Studio App**：利用者向けに導入・配布するアプリです。導入済みのAppを開き、用意された画面や処理を利用します。
- **Marketplace**：提供されているAppを探し、内容や導入条件を確認する入口です。

業務に合う機能を新しく作る場合は、Studio Workspaceでの構築ガイドから始めます。すでに使うAppやProjectが決まっている場合は、その利用案内から始めてください。

## 自分の役割に合わせて使う

| 役割 | 主に行うこと |
|---|---|
| 利用者 | 共有されたProjectや導入済みAppを開き、会話・画面操作・Workflow実行などで業務を進めます。 |
| 作成者 | 業務の目的に合わせてAgent・Workflow・データ・Pageを組み合わせ、動作を確認します。 |
| 管理者 | メンバー、アクセス権、共有接続、認証情報などを管理し、継続して使える状態を整えます。 |
| 開発者 | 必要に応じてPageのコードやSDK・APIを使い、画面や処理を開発します。 |

ここでの「役割」は、マニュアルの読み方を示す分類です。製品上のロール名や、操作権限そのものを表すものではありません。同じ人が複数の役割を担当することもあります。

## 使い始める前に知っておくこと

### すべての機能でコードが不要なわけではありません

画面操作やAIとの対話で進められる作業があります。一方、Pageの開発、SDK・APIの利用、外部サービスとの連携では、技術知識が必要になる場合があります。

### 操作できる範囲は人や環境によって異なります

表示される機能や実行できる操作は、組織の設定、契約・提供条件、参加先、権限によって異なります。必要なAppやProjectが表示されない場合や、設定を変更できない場合は、管理者に確認してください。

### AIの回答や実行結果は確認して利用します

資料を参照して回答する構成でも、回答の正確さや必要な情報の網羅性が保証されるわけではありません。業務で使用する前に、参照元や処理結果を確認してください。データの更新や外部サービスへの操作を組み込む場合は、影響範囲を確認してから利用を始めます。
