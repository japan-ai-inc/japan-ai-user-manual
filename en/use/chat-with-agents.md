# Chat with an Agent and Check the Results
We will explain the steps from sending requests and questions to the Agent to checking responses, processing results, and deliverables. Whether you use it from an app or from a shared project, it is important to confirm the Agent and target data before making the request.
This article deals with conversations with existing agents. We do not create agents or change the settings of instructions, tools, or models.
## Before you start
- Check the App or Project to be used and the name and purpose of the Agent.
- Prepare the requested work and the information/files you can use.
- When searching, registering, sending, etc. to external services, check the connection to be used and the scope of operation.
- Know who to contact for access and connectivity issues.
If you haven't opened it yet, start with the next article.
- [Open the installed app and start using it](open-installed-app.md)
- [Start using a shared Project](start-with-shared-project.md)
> Screen notation, layout, and available operations vary depending on organization settings, Agent, authority, etc. The following is the flow to check using a web browser on your PC.
## 1. Select the Agent to use
### Start with App
1. Open the app you want to use.
2. Search for the agent you were directed to from the dashboard or navigation.
3. Check the name and description and select the Agent.
4. On the conversation input screen, confirm that the Agent you are using matches your purpose.
When the business home page opens, follow the conversation entrance provided within the page or the guidance of the person in charge. Not all apps display the same list of Agents.
### Start with Project
1. Open the shared Project.
2. Search for the target from the Agent on the home screen or from entrances such as "AGENT".
3. Check the name and description and proceed to the target Agent usage screen.
Please do not assume that directly making a request in the chat input field on the home screen and selecting a specified Agent are the same operation. If an Agent is specified by the person in charge, that Agent will be used.
**You do not need to edit the Agent settings to use the Agent. ** If you cannot find or use the desired Agent, please check the name, participation status, and execution privileges with the person in charge.
## 2. Request with purpose and conditions
In the input field, write at least ``what you want us to do,'' ``what you want us to target,'' and ``in what form you want us to return it.''
| What to write | Examples |
|---|---|
| Purpose | Create a draft response to the customer |
| Target/Scope | Use the explanation regarding contract renewal from the attached FAQ |
| Output format | Summarize in 3 items: conclusion, basis, and confirmation items |
| Conditions to follow | Don't make assumptions about things that are not in the materials; mark them as "confirmation required" |
| What you can do | Only create drafts and do not send emails or update data |
For example, if you want to prepare a draft answer with supporting materials, you can request the following:
> Please use the attached "Contract Renewal FAQ.pdf" to create a draft answer to the customer's question, "What are the renewal procedures required?" Divide into conclusion, evidence, and confirmation items, and indicate the headings and parts that provide evidence. If there is anything that is not written in the document, please mark it as ``confirmation required'' and do not send it by email.
This example shows how to write a request. We do not guarantee that the specified format, citations, or file reading will be successful. Review the results and supplement as necessary.
When requesting data to be sent externally or updated, please clarify the destination, update target, and execution scope. We distinguish between "draft" and "send", and "present update proposal" and "update actual data".
## 3. Attach the required files
If you want us to use your materials, make sure the attachment action is available and add your files before sending.
1. Open the entrance to add files, such as the "+" near the input field.
2. Select the target file.
3. Check the file name displayed in the attachment field and the upload status.
4. If there are any incorrect files, remove them from the attachment field before sending.
5. Verify that the upload is complete and there are no errors.
6. In your message, write which files will be used for what purpose.
Supported formats, number of attachments, and capacity vary depending on the Agent used and settings. Follow the instructions on the screen. You may not be able to attach or send anything in a read-only conversation.
**Selecting a file is different from completing the upload. ** If you can't send, check for attachments that are still being processed or have failed. Also, please do not assume that you were able to accurately read the entire text, images, and tables of the document just because you were able to attach it.
When using multiple materials, specifying the role of the materials will make it easier to organize them, for example, "Give priority to Regulation A and check the differences from Material B."
> Attaching local files, referencing Datasets, and retrieving from external services are other methods. Just writing a file name or URL does not necessarily mean that the Agent can access that information. If you cannot refer to the document, check [Agent does not refer to data](../troubleshooting/agent-not-using-data.md).
## 4. Submit and check progress
1. Review the Agent, request text, attached files, and operation targets.
2. Select "Send" or the send icon.
3. Verify that your request appears in the conversation.
4. Check the response and processing status, read and respond to any additional questions or confirmations.
How you send with the keyboard varies depending on your settings. Don't assume that the Enter key will always result in a line break or always result in a send; check the instructions on the screen.
If you cannot use the send button, check whether the attachment is being processed, the input content, the read-only status of the conversation, the status of the Agent/model you are using, etc. You may be able to send additional instructions during the process, but it will be easier to understand the situation if you first check the results before proceeding to the next request.
If you're asked to connect an external account, check whether it's a personal connection you want to set up, or a shared setting provided by your administrator. Please use the specified settings screen instead of pasting the authentication information into the request.
> Even if communication is interrupted or the response stops, please do not resend the same request immediately. Processes that involve registration, updating, and sending may have already been completed. Check the outcome of the conversation and the actual destination of the update before making a decision.
## 5. Check answers and execution results
When the AI ​​answer is displayed, check it against the purpose of the request before accepting it.
| What to check | What to check |
|---|---|
| Answer content | Does it answer the question? Are there any important conditions or exceptions left out? |
| Numbers, dates, names | Do they match the original documents and business data? |
| Evidence | If there are citations or references, do they actually support the content? |
| Unclear points | Are conjectures and unconfirmed matters distinguished from facts? |
| External operation | Is the specified registration, update, and transmission completed for the target service? |
| Product | Can you actually open a file or document with the desired format and content |
Do not rely on the statement "Executed" to confirm the success of an external operation. Display the processing results and check at the update destination for which you have authority. On the other hand, it is important not to assume that something has not been executed just because you do not see a response.
If you don't know the basis for your answer, ask in the same conversation, ``What part of the material did you base your answer on?'' However, additional answers will also be checked. For important decisions, cross-check the evidence presented with the source material.
### Receive the artifact file
If the file was output, check the file card in the conversation and the download operation.
1. Check the file name and format. If there is a modified version with the same name, also check which response created it.
2. If Preview or Canvas is available, open it and review its contents.
3. Download the required files and save them to a location approved by your organization.
4. Open the saved file and check the content, format, and presence of omissions.
Display and preview methods vary depending on the file type and available features. **Just because the file name is written in the message body does not necessarily mean that the file that can be received is attached. ** If you don't see the card or link, ask, "Please share the file you created so it can be received in this conversation."
Even if you change the content in Canvas, do not assume that the previously downloaded file will be automatically replaced; instead, check the version you need before saving. If you see a save error, do not assume it has been saved.
## 6. Edit in the same conversation/Restart from history
### Make further requests or corrections
If you want to continue modifying the same material or answer, write an additional request in the conversation. Be specific about what you'll keep and what you'll change.
> Please leave the ``conclusion'' of the previous draft answer as is, and list the ``confirmation points'' in bullet points. Do not add new facts.
If you want to move on to a different customer, project, or purpose, it will be easier to organize the conversation by breaking it up into a new conversation. In a new conversation, specify the information you need instead of assuming that the material and decisions from the previous conversation will automatically be inherited.
### Open past conversation
1. Open the App/Project you were using.
2. Open the entrance to the app's "chat room" or the conversation list/history in Project.
3. If a search or filter appears, find the conversation you're looking for. If you cannot find it, review your search conditions and display targets.
4. Open the conversation and check the previous request/result/Agent before continuing.
Just because you can read a shared conversation doesn't mean you can provide additional input. Also, just because you are participating in a Project, you cannot necessarily see all the conversations of everyone.
When sending a link to a conversation to someone else, be sure to check the scope of sharing and the materials, personal information, and confidential information contained within. Just sending a link does not necessarily give the recipient permission to view it.
## When things don't go well
| Situation | Things to check first |
|---|---|
| Agent not found/unusable | App/Project, Agent name, participation status, execution authority |
| Unable to attach files | Supported formats, screen restrictions, upload status, conversation operation privileges |
| Unable to send | Input content, attachment completed, processing status, read-only display, screen error |
| The answer is not based on the materials | Specified Agent and materials, success or failure of attachment, reference settings and external connections |
| External operation fails | Required connection, authority, and target data. Check whether processing has been completed before re-running |
| Unable to open or retrieve artifacts | File cards in conversations, error displays, and file names. Ask to re-share if necessary |
| Can't find past conversations | Display targets for organizations, apps, projects, search conditions, sharing, archives, etc. |
If the problem is not resolved, inform the person in charge of the Agent name, the target App/Project, the date and time of occurrence, the operation details, and the displayed message. Please do not send passwords, API keys, or unnecessary personal information.
## Confirmation list for operation completion
- [ ] You have selected an agent that suits your purpose.
- [ ] Specified the target material, output format, and execution range.
- [ ] When using an attachment, the file name and upload completion were confirmed.
- [ ] Confirmed the content and basis of the answer.
- [ ] Confirmed the actual results of external operations and deliverables, not just the text.
- [ ] Unknown processing results are not re-executed without checking.
