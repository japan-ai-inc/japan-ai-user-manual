# Get Started in a Shared Project

This article explains how to open a Project shared by the person in charge and begin using prepared Pages, Agents, Workflows, and other features. **A Project is not a place only its creator can use. Users can use permitted features in an existing Project.**

This article does not cover creating a new Project or App. Adding members, changing permissions, and building features are also outside its scope. To use an installed App, see [Open an Installed App and Get Started](open-installed-app.md).

## What you can do with this procedure

- Open the Project you need from a shared link or a list.
- Complete required checks in response to guidance about joining or access.
- Select the features required for your work from existing resources in the Project.

## Before you begin

Confirm the following information with the person who shared it with you.

| Item to check | What to check |
|---|---|
| Where you will use it | The organization name, Project name, and shared link |
| Account to use | An account authorized for use by the organization |
| Features to use | Names of Pages, Agents, Workflows, and other features, plus your first task |
| Scope of your actions | Whether you only view, or also run, enter, or update information |
| Contact | The Project administrator or the person who provided usage guidance |

For signing in and checking your organization, see [Getting started requirements and basic screens](../getting-started/getting-started-and-navigation.md).

> **Sharing a link and granting access permissions are separate.** Even if you belong to the organization, you may not be able to use that Project or individual features. Ask the person who shared it whether you need to be added as a user.

## 1. Open the shared Project

### Open it from a shared link

1. Open the link provided by the person in charge.
2. If you are prompted to sign in, sign in with the specified account.
3. Check that the organization and Project you will use match the guidance you received.
4. If the home screen or the Page, Agent, or other item you were given opens, check it and proceed to use it.

If the link points to an individual Page, conversation, or other item rather than the whole Project, that screen may open directly. If you do not know the target, ask the person in charge for the Project and feature names.

### Find it from the Studio Workspace list

If you do not have a shared link or want to reopen the Project later, find it in the list.

1. Open the organization you will use this time.
2. Open the Studio Workspace entry point, such as "Workspace," in the navigation. It may appear under "Studio."
3. Enter the Project name you were given in "Search by project name."
4. Check the name and description, then open it from the target Project-name link.

Tabs such as "Joined Projects" and "All Projects" may be displayed. Tabs are not necessarily displayed for everyone, and **being visible in "All Projects" does not guarantee that you can use it.**

If the Project name is not a link or "Not assigned" is displayed, proceed to the following checks for joining and access. If you cannot find it by searching, clear the search term and check again. If you still cannot find it, ask the person in charge to check the link and your participation status.

> You do not need to create or duplicate a Project in order to use an existing Project. Even if you create another Project, data and access permissions from the shared Project are not necessarily carried over.

## 2. Check guidance about joining and access

If you can already use it, the screen opens without a joining action. Check the details only if guidance is displayed.

| Display or status | What to do |
|---|---|
| The Project or intended screen opens directly | Check the target and proceed to the feature you will use. |
| "Join" is displayed | Read the destination and description, and check whether it matches the role you were given. |
| "Not assigned" is displayed and you cannot join | Ask the person in charge to add you as a user or grant required permissions. |
| You return to the list or cannot access it | Check the account, organization, link, and participation status. Do not determine the cause based only on the screen change. |
| A connection-source restriction is displayed | Check conditions for use, such as the network specified by the organization. |

The joining confirmation may show an explanation that indicates **joining as an administrator**, such as "Join this project as Admin?" Do not proceed assuming it is the same as ordinary user enrollment.

- If you were instructed to manage the Project and the target and role match, confirm that you want to join and check that the Project opens.
- If you are responsible only for using it, or your role is unclear, use "Back," "Cancel," or a similar option to go back, then ask the person in charge how to be added.

Not everyone needs to become an administrator. Also, joining a Project does not necessarily permit you to view, run, edit, and delete everything.

## 3. Check the first screen that opens

The screen immediately after you open a Project varies by its configuration.

### When a home Page for business use opens

A web screen for users, such as an input form or list, opens. Follow the instructions on the screen and proceed with the action provided by the person in charge.

The usual Project navigation may be hidden on a home Page. It is not necessarily a problem if you cannot see menus for building features. An entry point to return to the Project screen may also not be displayed, depending on the configuration and your permissions.

If you cannot find the action you need, ask the person in charge which screen to use. You do not need to rewrite the URL or change Project settings to display a menu.

### When the Project home screen opens

Check the Project name and description, chat input field, Agents, Pages, and shared conversations. Displayed content varies by the Project's configuration and availability conditions.

If a particular Agent or Page is specified, select that item. Do not assume that making a request in the first chat input field you see is the same action as selecting the specified Agent and making a request.

## 4. Proceed to the existing feature that fits your purpose

The Project navigation may include entry points such as "AGENT," "PAGE," "WORKFLOW," "OBJECT," "STORAGE," and "DATASET." Some screens may display them in Japanese.

You do not need to open every feature in order. Begin with the target provided by the person in charge.

| What you want to do | Entry point or target to find | Next article |
|---|---|---|
| Enter information and review it in a prepared business screen | The home Page, or the target Page in "PAGE" or a similar area | [Move Your Work Forward from a Page](work-with-pages.md) |
| Ask AI to do something or ask a question | The Agent on the home screen, or the target Agent in "AGENT" | [Chat with an Agent and Review the Results](chat-with-agents.md) |
| Review a shared conversation | A shared conversation on the Project home, or the conversation link you were given | [Chat with an Agent and Review the Results](chat-with-agents.md) |
| Run a prepared process | Find the published Workflow in "Workflows" within the Project, or open the run link provided by the person in charge. | [Run a Published Workflow](run-published-workflow.md) |
| View, enter, or update business data | The target Object in "OBJECT," or a Page that handles its data | [View and Update Object Data](view-and-update-object-records.md) |
| Obtain or save files | The target file or folder in "STORAGE" | [Use Files in Storage](use-storage-files.md) |

This table helps you identify entry points. Displayed items and actions you can use vary by feature status, Project configuration, and permissions.

**Distinguish using a feature from creating or editing it.** For ordinary business use, you do not need to rewrite an Agent's instructions or test a Workflow draft or publish it. If you open an editing screen and do not know where to use the item, ask the person in charge how to use the target.

## 5. Check connections and targets, then perform your first task

Features that use external services may require a connection to your own account or shared settings by an administrator.

- **When you are asked to connect your own external account:** Check the service and account you will use, then configure it on the authentication screen you were given. For detailed steps, see [Connect Your External Accounts](../operations/connect-your-external-accounts.md).
- **When shared connections, Secrets, or similar settings are required:** Check with the Project administrator. Do not accept someone else's authentication information or replace shared settings at your own discretion.

Once connections are ready, perform your first task.

1. Check the target Page, Agent, or Workflow and the data to process.
2. For actions involving email sending, data updates, file storage, or similar outcomes, check the destination, update target, and save location.
3. Use input approved for business use and perform the required action.
4. Check the result, processing status, save location, and other outcomes.

Being able to open a screen alone does not necessarily mean that you have run permission or that the connection is ready. Also, seeing an AI response and completing an update in an external service are different things.

If an error or interrupted response occurs, do not immediately repeat the same process; check the history and update destination. To avoid duplicate sends or registrations, ask the person in charge if it is unclear whether it has already run.

## When you cannot get started

| Situation | What to check first |
|---|---|
| The Project is not in the list | Organization, search term, shared link, account to use, and participation status |
| You can see the name but cannot open it | Not-assigned status, being added as a user, and access permissions |
| Your menu differs from other people's | Home Page settings, features you should use, and differences in permissions |
| The Project opens but you cannot use a specific feature | Viewing or run permission for that feature, publication status, and required connections |
| You cannot find shared conversations or data | The target name or link, sharing scope, and viewing permissions |
| The screen fails to load | The displayed error and date and time. Do not treat a loading failure as evidence that the Project does not exist. |

When asking for help, provide the Project name, target feature name, account to use, action you performed, date and time, and displayed message. Do not send passwords, API keys, or tokens, and hide unnecessary personal or confidential information in screenshots.

## Getting-started checklist

- [ ] I opened the organization and Project I was given.
- [ ] I checked guidance about joining and permissions, and access it in a way that fits my role.
- [ ] I know the names and entry points for the Pages, Agents, Workflows, and other features I will use.
- [ ] I checked whether I need a personal connection or shared settings.
- [ ] For my first action, I was able to check the result and update destination.
