# What Is Studio?

JAPAN AI Studio lets you combine AI-powered processing, business data, and user interfaces to create applications that fit your work and use them with your team.

You can incorporate AI into everyday work, such as answering questions based on materials, organizing registered data, and running processing in defined steps. In addition to creating your own, you can use shared Projects and installed Apps.

This article explains an overview of Studio and the types of work it can support.

## What you can do with Studio

In Studio, you combine only the features you need for your goal. You do not need to use every feature from the start.

| What you want to do | How to approach it in Studio |
|---|---|
| Answer questions while referencing materials | Prepare the materials to reference and create a setup where an Agent searches for the necessary information and answers. |
| Organize information such as deals and tasks | Create fields and records in an Object so that you can search, register, and update data. |
| Perform multiple processes in a fixed order | Build the processing steps in a Workflow and connect input through output of the results. |
| Provide screens that are easy for business users to use | Create Web applications such as input forms and list screens in a Page, and connect them to business processes. |
| Handle files as part of your work | Save files in Storage and create a setup that uses them from the required processing or screens. |

When integrating with external services, configure the supported connection method and required credentials. The available integrations and operations vary by the features provided, permissions, and connection settings.

## Example: Using Studio for task management

For team task management, you might use the following setup:

1. Save the task name, assignee, due date, and status in an **Object**.
2. Create screens in a **Page** for listing, registering, and updating tasks.
3. Have an **Agent** help organize the status of work and draft reports based on registered information.
4. As needed, build aggregation and reporting processes in a **Workflow**.

This is a configuration example. Not everything is configured from the start; creation, connections, and permission settings that fit your work are required.

You can start with one goal, such as organizing task information, and add features as they become necessary.

## Where to build and where to start using Studio

Studio provides entry points for building and using.

- **Studio Workspace**: An area for creating and managing Agents, Workflows, Pages, and more by Project.
- **Project**: A unit that brings together the data and features needed for work and is used with members. People who do not build can also use the features of Projects they join, within their permissions.
- **Studio App**: An application installed and distributed for users. Open an installed App to use its prepared screens and processes.
- **Marketplace**: An entry point for finding available Apps and reviewing their content and installation conditions.

To create new features for your work, start with the building guides in Studio Workspace. If the App or Project you will use has already been decided, start with its usage guide.

## Use Studio for your role

| Role | What you mainly do |
|---|---|
| User | Open a shared Project or installed App and move work forward through conversations, screen operations, Workflow runs, and more. |
| Creator | Combine Agents, Workflows, data, and Pages according to the business goal and verify how they work. |
| Administrator | Manage members, access permissions, shared connections, credentials, and more to maintain an environment that can continue to be used. |
| Developer | As needed, develop screens and processing using Page code, SDKs, and APIs. |

The "roles" here categorize how to read this manual. They do not represent product role names or permissions themselves. One person may have multiple roles.

## What to know before you start

### Not every feature requires no code

Some tasks can be completed through screen operations or conversations with AI. On the other hand, Page development, SDK and API use, and integration with external services may require technical knowledge.

### The operations available vary by person and environment

The displayed features and executable operations vary by organization settings, contract and availability conditions, the resources you join, and permissions. If a required App or Project is not displayed, or you cannot change settings, contact an administrator.

### Review AI responses and run results before using them

Even when a setup answers based on referenced materials, the accuracy of its answers and completeness of the necessary information are not guaranteed. Review the sources and processing results before using them for work. If you include data updates or operations on external services, review their scope of impact before beginning to use them.
